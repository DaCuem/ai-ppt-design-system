# 图表与结构图指南（Charts and Diagrams）

图型由「问题类型」决定，不由「哪个图好看」决定。每张图先回答：观众要比什么、看趋势、看构成、看分布，还是看两个量的关系。

**基准**：16:9 画布 13.333×7.5 in。图表通过 `deck.schema.json` 的 `chart` 元素写入；`chartType` ∈ column/bar/line/area/pie/donut/scatter，`unit` 与 `source` 必填，`directLabel` 默认 true。结构图用 `rect`/`line`/`polygon`/`text` 组合绘制。

## 1. 选型决策树

| 观众要做的判断 | 图型 | 上限条件 |
|---|---|---|
| 比较若干类别的多少 | 柱图 column（类别 ≤ 7）／条形图 bar（类别名长或 > 7） | 类别 ≤ 12，超出改为表格 |
| 看随时间的变化 | 折线图 line（序列 ≤ 4）／面积图 area（只强调累计量） | 数据点 ≤ 24，超出按季度聚合 |
| 看整体由什么构成 | 堆叠柱/条（段 ≤ 5）／饼图、环图（扇区 ≤ 5，单层） | 段 > 5 时归并为「其他」 |
| 看数值分布 | 直方图（用 column 模拟）／箱线图（必要时） | 分组 ≤ 6 |
| 看两个量的关系 | 散点图 scatter；第三维用点面积编码 | 点 ≤ 100，超出降透明度 |
| 只要突出一个数 | 不用图表，用 `kpi` 大字（48–96 pt）+ 一句解释 | 单值一律不画图 |

**什么时候用表格不用图**：精确值需要读到小数位；同时比较 ≥ 3 列属性；单位不一致；任意两值差异 < 5%（图上不可辨）；数据有缺失项需要显式留空；需要列出待补项。表格用 `table` 元素，`fontSizePt` ≥ 11，行数 ≤ 8，列数 ≤ 6，`emphasisCol` 只标 1 列。

**规则：选型先写一句话**
- **触发条件**：该页需要呈现 ≥ 3 个数值。
- **具体动作**：先在图表标题位置写「这张图让观众看出：____」，再按上表选图型；若这句话填不出具体的比较或趋势，改为表格或 `kpi` 大字。单页图表 ≤ 2 个，同一页两张图的单位必须一致。
- **常见错误**：把 6 个部门的 6 项指标塞进一张堆叠柱，观众只能看出「柱子很花」，看不出任何结论。

## 2. 六类图的具体参数

| 图型 | 关键参数 | 明确禁用 |
|---|---|---|
| 柱图 / 条形图 | 柱宽 = 槽宽的 55%–70%；柱间隙 = 槽宽的 30%–45%；基线必须为 0；圆角 ≤ 2 pt 或直角；类别按值排序（时间序、等级序除外） | 3D、投影、图案填充、柱间接缝 < 0.1 in |
| 折线图 | 线宽 2–3 pt；数据点直径 4–6 pt（点 ≤ 12 时显示）；参考线 ≤ 1 pt、灰度 ≥ 20%；序列 ≤ 4 条 | 平滑曲线穿过未测区间、虚线表示实测值、双 y 轴未标注 |
| 饼图 / 环图 | 扇区 ≤ 5；起始 12 点方向、由大到小顺时针；环图环宽 = 外径的 25%–35%；扇区标签直接标注 | 3D、爆炸扇区、扇区 < 3%、多环嵌套比较 |
| 面积图 | 填充透明度 20%–40%（堆叠时 40%–60%，叠加时 20%–30%）；描边 1.5–2 pt；层数 ≤ 3 | 不透明填充遮挡下层、层序随页变化 |
| 散点图 | 点直径 4–8 pt；重叠点多时透明度 40%–70%；用面积编码第三维时面积比 = 值比（不是半径比） | 按半径编码值、无坐标轴单位、把相关当因果 |
| 表格 | 字号 ≥ 11 pt；行 ≤ 8、列 ≤ 6；表头加粗 + 5%–10% 底纹；数字右对齐、单位写进表头 | 全表加粗、斑马纹超过 2 色、单元格内换行 > 2 行 |

**规则：参数越界即返工**
- **触发条件**：`chart` 元素渲染完成或设计稿定稿前。
- **具体动作**：按上表逐项核对柱宽、线宽、透明度、扇区数；越界项改参数而不是改数据。柱图基线非 0 时，必须把轴断点符号与注释写在同一页。
- **常见错误**：为让差异明显把柱图基线设到 80，8% 的差距在图上看起来像 4 倍。

## 3. 必须元素与缺失处理

每张数据图必须同时具备四项：**单位**（写进轴名或图内标注）、**来源**（页脚 `source`，含机构与年份）、**n=**（样本量，写进副标题或脚注）、**时间口径**（统计区间、截止日期、时区）。另需注明口径变化、汇率、估算值标记。

| 缺失项 | 处理 |
|---|---|
| 单位 | 无法确认时改画结构图或删图，不猜 |
| 来源 | 无来源即视为不可用，删除该图（P0 阻断） |
| n= | n < 30 时不画百分比构成，改为「列原始数量」或定性表述 |
| 时间口径 | 补「截至 YYYY-MM」；跨期比较必须标注两个区间 |

**规则：四项缺一不入版**
- **触发条件**：任何 `chart` 元素提交渲染前。
- **具体动作**：四项逐项打勾；缺项先向数据提供方确认，确认不到就把该页从「证据页」改为「说明页」，措辞从「增长 32%」降级为「据团队记录，呈上升趋势」。
- **常见错误**：图很漂亮但没写 n= 与统计区间，被问「这 32% 是环比还是同比」时无法回答。

## 4. 误导性图表清单

1. **截断轴**：柱图基线非 0；折线截断未标断点。柱图 0 起，折线截断必须画断点符号 + 文字说明。
2. **双轴滥用**：仅在两个量单位不同且都要看走势时使用，最多 2 轴；两轴颜色必须与对应序列一致，轴标题写单位。
3. **面积/体积夸大**：3D 饼、按半径编码数值、把图标放大 2 倍表示 2 倍。
4. **无基线的比较**：两个饼图并排比大小而扇区基准不同；百分比不写分母。
5. **样本量不标**：n < 30 仍画分布或占比。
6. **时间轴等距但周期不等**：把 3 个月与 9 个月的区间画成等宽。
7. **累计与当期混用**：同一图里既有累计值又有单期值，未分开标注。
8. **选择性区间**：只截取对结论有利的时间段，未说明选取理由。

**规则：出现任一即 P1 返工**
- **触发条件**：图表自检或评审。
- **具体动作**：按清单 1–8 逐条核对；命中项改图或改文案，不得只加脚注掩盖。审图人必须在评审记录里写明检查了哪几条。
- **常见错误**：用双轴让两条不相关的线「看起来同步上涨」，观众据此得出错误因果。

## 5. 直接标注与图例的选择

**用直接标注**（`directLabel: true`，默认）：序列 ≤ 4 条、标签 ≤ 8 字；标注放在线末端、柱顶、扇区外侧；标注字号 ≥ 11 pt，与图形距离 0.05–0.1 in。

**用图例**：序列 ≥ 5 条，或标签长度 > 8 字；图例置于图表上方或右侧单行，色块 8×8 pt，条目间距 ≥ 12 pt，图例不与图形重叠。

**用注释而非图例**：阈值线、目标线、异常点、口径变化，用 1 pt 引线 + 文字直接标在对应位置。

**规则：能直接标就不放图例**
- **触发条件**：图表需要让观众区分 ≥ 2 个序列。
- **具体动作**：先尝试直接标注；标注会互相遮挡时（间距 < 0.1 in）才退到图例，且图例条目顺序与图形绘制顺序一致。
- **常见错误**：4 条线配 4 色图例，观众要来回扫视对照颜色，读完图已经忘了结论。

## 6. 流程图与结构图的四种画法

| 画法 | 适用 | 节点数与尺寸 | 关键参数 |
|---|---|---|---|
| 线性流程 | 步骤、阶段、时间推进 | 3–6 个节点 | 节点 2.4×0.9 in，间距 0.4 in，箭头 1.5 pt，方向统一从左到右或从上到下 |
| 分支 | 判定、条件路径 | 1 根 + 2–3 支，层级 ≤ 3 | 分支节点 1.8×0.9 in，判定菱形对角线 ≤ 1.2 in |
| 泳道 | 跨角色协作 | 2–4 条泳道 | 泳道高 ≥ 1.4 in，表头 0.5 in，泳道间距 0.15 in |
| 层级 / 树 | 组织、分类、架构 | ≤ 4 层，每层 ≤ 5 节点 | 同层节点顶边对齐，层间距 0.6–0.9 in，连接线直角折线 |

**节点尺寸网格**：所有节点宽高取 0.2 in 的倍数，对齐 12 列网格（列宽 0.911 in、间距 0.2 in）；节点内文字 ≤ 12 字、≤ 2 行，字号 ≥ 11 pt；同级节点尺寸必须完全相同。

**规则：先画骨架再放字**
- **触发条件**：需要表达 ≥ 3 个环节的流程或 ≥ 5 个单元的层级关系。
- **具体动作**：先定画法与行列数，用等尺寸 `rect` 摆网格，再连线，最后填字；连线不穿过任何节点，交叉处加减号跳线或改走线。流程节点 ≤ 6，超出拆成两页（第 1 页总览、第 2 页展开）。
- **常见错误**：每个节点大小随文字长短变化，连线歪斜，观众先看到「乱」再看到内容。

## 7. 信息图分层

页面元素按四层组织，`zRole` 从下到上：

| 层 | 内容 | `zRole` | 约束 |
|---|---|---|---|
| 背景层 | 底色、底纹、满版图 | `bg` / `bgDecor` | 不承载信息；对比度留给上层 |
| 结构层 | 参考线、坐标轴、连接线、容器 | `content`（细线）/ `bgDecor` | 线 ≤ 1 pt；轴 ≤ 1.5 pt |
| 数据层 | 柱、线、点、扇区、面积 | `content` | 颜色按语义映射（见 [色彩指南](./color-guide.md) §6） |
| 标注层 | 标题、数值、单位、注释、来源 | `content` / `fgDecor` | 字号 ≥ 11 pt；数值标签不与图形重叠（间距 ≥ 0.05 in） |

**规则：标注层最后放、最先读**
- **触发条件**：一页同时有图形、文字、装饰。
- **具体动作**：按背景 → 结构 → 数据 → 标注顺序添加；标注层元素放在最上，且保证遮住装饰层不影响阅读。标注层文字不得压在数据图形的密集区（重叠 > 5% 即改位置）。
- **常见错误**：来源行压在坐标轴刻度上，刻度读不出、来源也被裁掉。

## 检查清单

- [ ] 每张图都能用一句话写出「让观众看出什么」，且与所选图型匹配。
- [ ] 柱图基线为 0，柱宽为槽宽的 55%–70%，间隙 30%–45%。
- [ ] 折线宽 2–3 pt，序列 ≤ 4 条，实测区间未被平滑曲线穿越。
- [ ] 饼/环图扇区 ≤ 5，无 3D、无爆炸扇区。
- [ ] 面积图填充透明度在 20%–40%（堆叠 40%–60%），层数 ≤ 3。
- [ ] 每张图都有单位、来源、n=、时间口径四项，缺项已按 §3 降级处理。
- [ ] 未出现截断轴、双轴滥用、面积夸大、无基线比较之一。
- [ ] 序列 ≤ 4 时使用直接标注；使用图例时条目顺序与绘制顺序一致。
- [ ] 流程节点 ≤ 6、层级 ≤ 4 层，同级节点尺寸完全一致且对齐 0.2 in 网格。
- [ ] 节点内文字 ≤ 12 字、≥ 11 pt，连线未穿过任何节点。
- [ ] 信息图四层顺序正确（背景 → 结构 → 数据 → 标注），标注未压数据密集区。
- [ ] 表格行 ≤ 8、列 ≤ 6、字号 ≥ 11 pt，`emphasisCol` 只标 1 列。
