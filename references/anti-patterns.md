# 反模式清单（anti-patterns）

反模式不是品味问题，而是每页都能截图举证的结构错误。下面 16 条按出现频率排序，每条 5 栏：症状＝**触发条件**（肉眼可观察的现象）／模型先验（AI 为什么会这样）／判据＝**常见错误** 的量化证据／修正动作＝**具体动作**（参数 + 替换版式编号）／替代做法。

替换用的版式编号见 [layout-recipes.md](layout-recipes.md)；判据里的阈值见 [thresholds.json](../schema/thresholds.json)，两者冲突时以 thresholds.json 为准。

## AP-01 统一圆角卡片墙

- **症状**：每页 2×2 或 3×2 同尺寸圆角卡片，圆角半径 12–24 px，全本看不出重点。
- **模型先验**：语料里卡片是通用容器，模型复用组件而非重排版式。
- **判据**：同一圆角半径出现于 ≥ 50% 页面；单页同尺寸卡片 ≥ 3 张。
- **修正动作**：卡片 ≤ 2 张/页、圆角 ≤ 8 px；换 L04 或 L13，相邻页改 gridTemplate。
- **替代做法**：用"结论句 + 证据 + 一行解读"分层，分组靠留白（≥ 25%）与字号。

## AP-02 四宫格强行套用

- **症状**：4 个等大方框占满内容区，最长框字数是最短框的 2 倍以上。
- **模型先验**：四宫格在语料里等于"有结构"，模型用它替代真实分类。
- **判据**：单页 4 个等面积框且无 2×2 二维关系；最长/最短字数比 ≥ 2。
- **修正动作**：3 条 → L13 三栏 5:4:3；4 条等权 → L08 B 指标墙；有二维轴 → L09 A。
- **替代做法**：四条结论排一行，按字数给栏宽（各 3–5 栏），余下设留白（≥ 25%）。

## AP-03 左右 5:5 分栏

- **症状**：每页左文右图各 6 栏，正文每行 40 字以上，连排 ≥ 3 页。
- **模型先验**："左图右文"是模板最省事的构图，语料频次最高。
- **判据**：左右栏宽比 5:5 ± 0.5 栏；正文每行 > 34 字。
- **修正动作**：改 7:5 或 8:4（图 col1–8、方法 col9–12）；正文 ≤ 34 字/行；用 L04。
- **替代做法**：比例由内容量决定：图为主 8:4，文字为主 4:8。

## AP-04 图标堆叠

- **症状**：3–5 个同尺寸线性图标横排，每个配 2 行小字，是页面唯一图形。
- **模型先验**：icon + 标题 + 描述是 UI 组件结构，模型把界面当幻灯片。
- **判据**：单页图标 ≥ 3 个且尺寸相同；图标下文字 ≤ 2 行且无数字。
- **修正动作**：图标 ≤ 3 个、视觉重量 ≤ 24 px；主结构换 L10 或 L07，改编号 + 动作名。
- **替代做法**：用编号或真实截图承担视觉，删掉整排图标。

## AP-05 渐变 + 玻璃拟态

- **症状**：紫蓝渐变底 + 半透明模糊卡片 + 白描边，正文发灰看不清。
- **模型先验**：2020–2023 年 UI 语料把渐变与毛玻璃当默认皮肤。
- **判据**：整本 ≥ 2 页用渐变底；卡片不透明度 < 90%；正文对比度 < 4.5:1。
- **修正动作**：底改纯色（明度差 ≥ 20）；卡片不透明；正文 ≥ 4.5:1、大字 ≥ 3:1。
- **替代做法**：用一张实拍照片或一块纯色建立氛围，见 visual-styles.md。

## AP-06 无意义装饰线 / 色块

- **症状**：标题下横线、左侧竖色条、右上角三角，删掉后信息不变。
- **模型先验**：模板用横线分隔段落，模型用它填满内容区。
- **判据**：删掉后信息与层级不变的元素 ≥ 2 个/页。
- **修正动作**：装饰 ≤ 1 个/页且必须承担分组或指向；其余删除，分组用 0.2 in 栏间距。
- **替代做法**：靠对齐与字号分层；色块只用来承载数据（条形底色）。

## AP-07 标题居中 + 副标题 + 英文小字三件套

- **症状**：每页居中标题 + 副标题 + 全大写英文一行，20 页同款。
- **模型先验**：官网 hero 区与企业模板都是这三行，模型把"页头"学成套式。
- **判据**：≥ 60% 页面用居中三件套；英文小字与中文标题语义重复。
- **修正动作**：标题左对齐起于 col1、删重复英文；居中页 ≤ 2 页（仅 L01 / L15）。
- **替代做法**：标题写成结论（L04 式），副标题信息并入标题或图注。

## AP-08 每页三段 bullet

- **症状**：每页 3–5 条 bullet，句式雷同，每条 ≤ 20 字且无数字。
- **模型先验**：列表最省 token，模型把"内容"直接映射成 bullet。
- **判据**：单页 bullet ≥ 3 且全本 ≥ 60% 页面；每条无数字或单位。
- **修正动作**：bullet ≤ 3 条/页；有先后改 L06 / L07，并列改 L13；每条补 1 个数字。
- **替代做法**：一条结论一页（L04），证据用图不用列表。

## AP-09 封面大标题 + 副标题居中套餐

- **症状**：封面标题居中 + 副标题居中 + 底部日期，元素 ≥ 4 个。
- **模型先验**：发布会 KV 与模板封面都是居中构图。
- **判据**：封面标题居中且副标题 ≤ 2 行；封面元素 ≥ 4 个。
- **修正动作**：按 L01：标题 col1–8 压左下、标识 col9–12、元素 ≤ 3；标题 56–96 pt。
- **替代做法**：用一张真实产品图做底，标题压低对比区（对比 ≥ 3:1）。

## AP-10 字体超过 3 族

- **症状**：标题无衬线、正文宋体、引文手写体、数字另配一款，同页 4 种。
- **模型先验**：语料把"标题 / 正文 / 强调"当三个字体槽位分别选。
- **判据**：整本字体族 > 3；同页字重 > 3 种；中英混排字体不一致。
- **修正动作**：字体族 ≤ 2（中文 1 + 数字 1）、字重 ≤ 3；层级用 ≥ 1.25 倍字号差。
- **替代做法**：只用字号、字重、颜色三者组合分层。

## AP-11 低对比灰字

- **症状**：正文 #999 压在浅底，投影后几乎不可读；图注更浅。
- **模型先验**：网页语料用浅灰表示次要信息，模型只学了颜色没学场景。
- **判据**：正文对比度 < 4.5:1；图注 < 3:1；最浅文字与底色明度差 < 40。
- **修正动作**：正文 ≥ 4.5:1、大字 ≥ 3:1、非文字 ≥ 3:1；图注 11–14 pt 同样 ≥ 4.5:1。
- **替代做法**：用字号（16 → 11–14 pt）与位置区分次要，不靠降对比。

## AP-12 图表无单位 / 无来源 / 3D 饼图

- **症状**：纵轴无单位、图下无来源与 n、饼图带 3D 透视与阴影。
- **模型先验**：图表库默认模板省略单位来源；3D 在旧演示里等于"专业"。
- **判据**：轴无单位或 0 点截断未标注；无来源 / n；饼图 3D 或切片 > 7。
- **修正动作**：轴带单位 + 0 起点（截断标断轴）；图下 11–14 pt 来源 + n；饼图改条形，切片 ≤ 7。
- **替代做法**：一个数字能说清就用 L08，不画图。

## AP-13 假数据与假合影

- **症状**：编造增长率、客户 Logo 墙出现不存在公司、AI 合影当团队照。
- **模型先验**：任务要求"看起来完整"，模型宁填占位数字也不留空。
- **判据**：出现无来源具体数字；Logo 或人像无法追溯到真实素材；人像手指或文字异常。
- **修正动作**：无来源数字改定性或删除；Logo 只放已授权；无真实团队照则删该页（L15 A）。
- **替代做法**：留"待补数据"标记给作者；示意图必须标注"示意"。

## AP-14 emoji 当图标

- **症状**：标题前后出现火箭或闪光 emoji，bullet 用对勾 emoji，与正文同字号。
- **模型先验**：社媒语料里 emoji 是零成本视觉，被当成强调手段。
- **判据**：单页 emoji ≥ 2；emoji 出现在标题或页码区。
- **修正动作**：正式演示 emoji = 0；需标记用编号或 12 px 圆点，一处 ≤ 1 种。
- **替代做法**：用编号与版面位置做节奏。

## AP-15 把段落整段塞进页面

- **症状**：一页 300 字以上，正文 12–14 pt，每行 50 字，观众读不完。
- **模型先验**：文档语料整段搬入，模型把"信息完整"当"信息充分"。
- **判据**：单页 > 220 字；正文 < 16 pt；每行 > 34 字；文本块 > 4 个。
- **修正动作**：拆 2–3 页、每页 1 个主张（L04）；正文 16–24 pt、≤ 6 行 × 34 字。
- **替代做法**：段落压成一句结论 + 一个证据，长文进讲义或备注。

## AP-16 页码 / 页脚被装饰吞掉

- **症状**：页码压在图或色块上，与背景同明度；页脚超出安全边。
- **模型先验**：页脚是模板固定层，加背景图时不检查层级与对比。
- **判据**：页码对比度 < 3:1；页码距边 < 0.3 in；整本缺页码 ≥ 30%。
- **修正动作**：页码 9 pt、底栏 col11–12、对比 ≥ 3:1；该区域加 0.6 in 半透明压暗条。
- **替代做法**：页码只做 9 pt 纯文字，不加装饰底。

## 自检 10 问

以下每问可直接答"是 / 否"；答"是"即命中反模式，回到对应编号修正。

1. 是否有 ≥ 50% 页面使用同一圆角半径的卡片（AP-01）？
2. 是否有连续 ≥ 3 页使用同一版式签名（AP-01、AP-08）？
3. 是否有页面左右栏宽比落在 5:5 ± 0.5 栏（AP-03）？
4. 是否有页面图标或 emoji ≥ 3 个且不携带数字（AP-04、AP-14）？
5. 是否有页面字数 > 220 字或正文 < 16 pt（AP-15）？
6. 是否有文字对比度 < 4.5:1，或大字 < 3:1（AP-05、AP-11）？
7. 是否有图表缺单位、缺来源、缺 n 或使用 3D 饼图（AP-12）？
8. 是否有数字、Logo、团队照片无法追溯到真实素材（AP-13）？
9. 是否有装饰元素删掉后页面信息不变（AP-06）？
10. 是否整本页码齐全、位置一致、对比度 ≥ 3:1（AP-16）？
