# 演示节奏指南（Presentation Rhythm）

节奏是观众注意力的分配表。每页先定「停多久、承担什么、能量几级」，再决定放什么内容。

**基准**：16:9 画布 13.333×7.5 in；观众距屏 3–8 m；单页停留 45–90 s。数值与 `schema/thresholds.json` 的 `density`、`rhythm`、`repetition` 保持一致。

## 1. 叙事结构库

| 结构 | 页数 | 页序建议 |
|---|---|---|
| 问题—解决方案 | 6–10 | 封面 → 现状与问题证据（1–2）→ 问题代价（1）→ 方案主张（1）→ 方案机制（1–2）→ 验证证据（1）→ 落地路径（1）→ 结尾（1） |
| 背景—过程—成果 | 6–12 | 封面 → 目标与背景（1）→ 阶段或时间线（1–2）→ 关键过程（2–3）→ 成果数据（1–2）→ 不足与下一步（1）→ 结尾（1） |
| 论点—证据 | 5–9 | 封面 → 核心结论（1）→ 论据 A/B/C 各 1 页 → 边界与反驳（1）→ 结论重申（1） |
| 时间线 | 5–8 | 封面 → 起点（1）→ 节点页 3–5 → 现在（1）→ 未来（1） |
| 方案比较 | 5–8 | 封面 → 决策标准（1）→ 候选概览（1）→ 逐维对比（1–2，表格）→ 推荐与理由（1）→ 风险与迁移（1）→ 结尾（1） |

**规则：结构先写进元数据**
- **触发条件**：开始排版前。
- **具体动作**：在项目记录里写定结构名称、总页数、每页承担的功能（问题/证据/方案/对比/行动）；页数超出上表区间时，先删页而不是压缩单页内容。
- **常见错误**：边做边加页，最后 14 页里有 5 页在重复同一个论点，观众在第 6 页就开始看手机。

## 2. 页数与时长换算

| 页面类型 | 建议停留 | 备注 |
|---|---|---|
| 封面 | 15–40 s | 通常与开场语重叠 |
| 章节页 | 10–20 s | 只用一句短语，不解释 |
| 单点结论页 | 45–60 s | 1 个论点 + 1 个证据 |
| 图表证据页 | 60–90 s | 含「读出结论」的时间 |
| 结构图 / 流程页 | 60–90 s | 观众需要逐节点看 |
| 表格对比页 | 75–120 s | 超过 120 s 必须拆页 |
| 收尾页 | 30–60 s | 只讲行动与结论 |

**换算**：`讲稿时长 ≈ 页数 × 60 s`，扣除封面与结尾后再加 15% 弹性。20 min（1200 s）的演讲对应 16–20 页（按 60–70 s/页）；45 min 对应 36–45 页，且必须插入 ≥ 6 个章节页。

**规则：先定时长再定量**
- **触发条件**：单页内容量超出 `density` 上限（元素 > 14、文本块 > 4、要点 > 6、字符 > 220）。
- **具体动作**：按上表给该页定停留时长，若 90 s 讲不完，拆成两页（第 1 页结论、第 2 页证据），单页内容量随之下降；不得压缩字号或把留白压到 25% 以下来塞内容。
- **常见错误**：把 90 s 的证据页压成 40 s 快翻，观众还没找到坐标轴就被切走。

## 3. 视觉能量曲线（1–5）

能量定义：1 = 单句文字或单一数字；2 = 文字为主 + 小图；3 = 图文各半；4 = 大图/大数字/强对比；5 = 满版视觉 + 高对比 + 单点信息。

**原则**：开场 3–4；中段在 2–3 与 4 之间交替；全册能量 5 只出现 1–2 页；收尾回到 3。

| 示例（10 页产品发布） | 逐页能量 |
|---|---|
| 封面上→结尾 | 4、3、2、3、4、5、3、2、4、3 |
| 8 页季度汇报 | 3、2、2、3、2、4、3、3 |
| 6 页方案比较 | 3、2、3、2、4、3 |

**规则：能量 5 不连用、能量 1 不连三**
- **触发条件**：整册页序排定后。
- **具体动作**：给每页标 1–5，检查：能量 5 连续 ≤ 1 页、能量 1 连续 ≤ 2 页、任意连续 4 页中至少 1 页能量 ≤ 2。不满足就调页序或改版式，不改内容。
- **常见错误**：前 5 页连续满版大图，第 6 页开始全是文字，观众在前半段被喂饱、后半段走神。

## 4. 疏密交替规则

密度判定（与 JSON 一致）：高密度页 = 元素 ≥ 10，或（文本块 ≥ 3 且字符 ≥ 160）；低密度页 = 元素 ≤ 5、字符 ≤ 60、留白 ≥ 50%。

| 规则 | 阈值 | 落地做法 |
|---|---|---|
| 连续高密度上限 | 2 页（`maxConsecutiveDenseSlides`） | 第 3 页改为低密度：全页图、单一大数字、或章节页 |
| 视觉换气 | 每 4 页至少 1 次（`minVisualBreakEvery`） | 在第 3–4 页插入满版图页或 `kpi` 单数字页 |
| 内容区留白 | ≥ 25%（`minWhitespaceRatio`） | 版面留出至少 1/4 面积不放置图形与文字 |
| 着墨比例 | ≥ 6%（`minInkRatio`） | 防止整页几乎全空，文字与图形有最低存在感 |

**规则：高密度后必须换气**
- **触发条件**：页序中出现第 2 页连续高密度。
- **具体动作**：紧跟 1 页低密度，且该页只承担一个信息（一句结论或一个数字）；4 页窗口内没有低密度页时，优先把最不重要的一页改成低密度页。
- **常见错误**：连续 4 页数据表，每页都写「如上表所示」，观众在第 3 页就停止阅读。

## 5. 章节页的数量与位置

| 总页数 | 章节页数 | 位置 |
|---|---|---|
| ≤ 5 | 0 | 不设章节页，用标题体现结构 |
| 6–8 | 0–1 | 只在中点可选 1 个 |
| 9–12 | 2–3 | 每 4–6 页 1 个 |
| 13–20 | 3–5 | 每 4–5 页 1 个 |

章节页只出现在结构切换处；不得连续 2 页；单页元素 ≤ 4（序号 + 短语 + 底纹 + 页码）；短语 ≤ 12 字。

**规则：章节页是换气点，不是正文页**
- **触发条件**：总页数 ≥ 9。
- **具体动作**：先按结构切出 2–4 个章节，再在每章首页前插章节页；章节页不承载论点、不放数据、不念稿超过 20 s。
- **常见错误**：章节页上写满本章 5 个要点，观众在换气页又被灌入一轮信息。

## 6. 开场与收尾

**开场三选一**：① 结论先行——第 2 页直接给核心结论，后续解释依据（适合决策会）；② 情境引入——一个具体场景、一个数字或一句原话（≤ 3 句），再引出问题；③ 目标确认——说明「今天要决定什么」+ 议程 ≤ 4 项。

**收尾三选一**：① 行动清单——3 项，每项带负责人与时间；② 单句重申——≤ 25 字结论 + 1 个数字；③ 回到开场——呼应开场提出的问题并给答案。

**规则：90 s 内给出结论或议程**
- **触发条件**：任何正式汇报。
- **具体动作**：开场 90 s 内必须出现核心结论或明确议程；结尾页不出现新信息、不带新数据、不放待办之外的链接。
- **常见错误**：前 5 分钟讲公司历史与团队介绍，听众不知道今天要决定什么。

## 7. 重复与变化节奏

版式签名 = `layout` + `gridTemplate` + `focalPosition`（`repetition.signatureFields`）。阈值：相邻 2 页签名不得完全相同（`maxSameLayoutAdjacent` = 1）；同签名页占比 ≤ 35%（`maxSameLayoutShare`）。

**变化优先级（从高到低）**：焦点位置 → 网格（gridTemplate）→ 版式 → 颜色/字体。固定元素（页码、页眉线、来源行）位置全册不变，用来建立连续感。

**示例（6 页）**：`cover/full` → `split-left/tl` → `split-left/br` → `full-bleed/full` → `split-right/tr` → `closing/center`。

**规则：相邻两页至少换一个签名维度**
- **触发条件**：同一版式连续使用第 2 页。
- **具体动作**：改动 `focalPosition`（如 tl → br）或切换 `gridTemplate`；同时检查该签名占比未超 35%。固定元素不动，变化只发生在内容区。
- **常见错误**：全册 12 页都是「左文右图」，观众翻到第 4 页就分不清哪页是新内容。

## 检查清单

- [ ] 已选定叙事结构，每页功能可一句话说明，总页数落在该结构区间。
- [ ] 每页停留时间已标注，证据页 60–90 s，表格页 ≤ 120 s。
- [ ] 全册讲稿时长 = 页数 × 60 s ± 15%，与会议时长匹配。
- [ ] 每页标了能量 1–5；能量 5 未连续出现，能量 1 未连续 3 页。
- [ ] 任意连续 4 页中至少 1 页能量 ≤ 2。
- [ ] 连续高密度页 ≤ 2；每 4 页至少 1 页低密度/满版图/kpi 页。
- [ ] 每页内容区留白 ≥ 25%，着墨比例 ≥ 6%。
- [ ] 章节页数量符合 §5 表，未连续 2 页，单页元素 ≤ 4。
- [ ] 开场 90 s 内出现核心结论或议程（≤ 4 项）。
- [ ] 结尾页无新信息，行动项 ≤ 3 且带负责人与时间。
- [ ] 相邻页签名（layout/gridTemplate/focalPosition）不完全相同，单签名占比 ≤ 35%。
- [ ] 页码、页眉线、来源行位置全册一致。
