# 外部参考资源（further-reading）

`references/visual-styles.md` 的每种风格第 ⑭ 项、以及排版/色彩/图表/可访问性各篇，都需要一个"往哪里深挖"的出口。本文件就是那个出口：**只给链接与用途，不复述内容**。

## 0. 使用方式

1. **这是入口，不是依据。** 仓库里所有规则都在本地 Markdown 中写全了，不依赖外链才能工作；断网时本文件可以整篇跳过。
2. **引用前先回一手。** 百科与教程类条目只用来核对术语与年代，写进正式文档的史实与数值应回到博物馆档案、原始出版物或规范原文。
3. **不复制内文。** 本仓库不转载任何外部页面正文、图片或 PDF；许可列写"仅链接引用"的条目，意思是我们只放 URL，不分发内容。
4. **链接会腐。** 每个条目带核验日期；若打开是 404，先在本仓库提交 issue，再由维护者替换为同主题的替代源，**不要**凭印象改写成"某本书"来蒙混。

## 1. 核验说明（诚实标注）

本文件所有条目在 **2026-11-14** 做过可达性核验，分两种方式，表中以"核验"列区分：

- `200`：本机直接 HTTP 请求返回 200，页面可打开。
- `内容`：本机网络对该域被拦截（TLS 或超时），改由搜索桥抓取页面正文，返回了该页真实内容，据此判定存在。

没有第三条路：**凡是没能核验的链接，一条都不写进本文件**。

## 5. 已知缺口（不要以为覆盖全了）

- **没有任何一手出版物全文**。Müller-Brockmann《Grid Systems》、Hollis《Swiss Graphic Design》、Droste《Bauhaus》这类书只在风格条目里以书名出现，本仓库不提供获取渠道，也不复制内容。
- **Google Fonts 在本机网络被拦截**，因此 Noto Sans SC 的页面没有列进来（无法核验就不写）。需要时走 `assets/licenses.md` 的字体表，用系统已装字体或自备字体文件。
- **中文来源偏少**：Tate、MoMA 一类机构的中文页面覆盖不全，国内设计院校与出版机构的一手资料本版未纳入。补这一块需要能读中文期刊库的人来选，不是搜几条链接就能补齐。
- **只到"读什么"，没到"怎么看"**。真正的拆解方法在 `discovery/reference-analysis.md`（7 步拆解法），本文件只负责把可读的原始材料找出来。

## 6. 三条硬规则（把外部资源用进成片时）

**规则 1：外部资源只能当依据，不能当素材**

**触发条件**：页面上要放图、放表、放数据，且来源在仓库外。
**具体动作**：先按 `assets/licenses.md` 记 8 字段（素材 ID / 页 / 来源 / 许可 / 商用 / 署名 / 修改 / 核验），许可不明的直接不用；需要署名时把署名文字真实写进图注或页脚，不能只写在记录表里。
**常见错误**：把"网上找的""某图库"写进来源，或用 AI 生成图冒充实拍与真实实验结果。

**规则 2：史实与数值必须回到一手来源**

**触发条件**：文案里出现年代、人物、书名、机构规格（如"1981 年出版""12 栏""对比度 4.5:1"）。
**具体动作**：百科条目只用来定位术语，最终核对博物馆档案、出版社书目或规范原文；核对不了就把限定词写清楚（写成"据 XX 纪念馆档案"或直接删掉该数值）。
**常见错误**：拿二手博客当原始出处，把"大概 1980 年代"写成确定年份。

**规则 3：链接只是路标，成片里不出现裸链接**

**触发条件**：想在页面上直接贴一条 URL 当作"来源"。
**具体动作**：把来源写成可读形式（机构名 + 文献名 + 年份），URL 留在备注 `notes` 或交付说明里；确实需要二维码或短链时，先确认观众能拿到。
**常见错误**：页脚塞一串小字 URL，投到 3 m 外看不清，也没人会在投影上抄链接。
