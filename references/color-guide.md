# 色彩指南（Color）

从主题推导一套可用色，并给出可判定的对比度下限。所有色值写入 `deck.json` 的 `tokens.colors`，可用令牌名有 `bg`、`bgAlt`、`fg`、`fgMuted`、`primary`、`secondary`、`accent`、`warn`、`ok`。

**基准**：16:9 画布 13.333×7.5 in，观众 3–8 m，投影或 LED 大屏。单页面积按 13.333 × 7.5 = 100 in² 计。

## 1. 从主题推导色彩的四条路径

**路径 A｜品牌色（有 VI、logo 或既定主色时）**
- **触发条件**：用户提供了品牌色值、logo 或企业视觉规范。
- **具体动作**：1) 取 logo 主色记为 `primary` 原值；2) 饱和度 > 0.85（`color.saturationCapNormal`）时降到 ≤ 0.85 再用于大面积；3) 明度 L < 40% 可作深底与标题，L > 70% 只能作底色或色块；4) 由 `primary` 派生 L ±15%、±30% 的中间调；5) `secondary` 取邻近或互补色，全册色相数 ≤ 3（`color.maxHuesPerDeck`）。
- **常见错误**：把品牌高饱和色直接铺满背景，再用白字，投影后对比度虚高、画面发烫；正确做法是降饱和 + 压暗后再铺。

**路径 B｜素材取色（有主图或现场照片时）**
- **触发条件**：已有决定性图片，且希望页面与图片同调。
- **具体动作**：1) 对主图做 k=5 主色提取；2) 按像素面积降序排列；3) 面积最大者作 `bg`/`bgAlt` 基底；4) 饱和度最高或色相唯一的那个作 `accent`；5) 与 `fg` 做 §4 对比度校验，不达标则只调明度、不改色相。
- **常见错误**：五色全部上版，页面出现 5 个色相，读者分不清哪个是强调；抽出后必须按 60-30-10 重新分配面积。

**路径 C｜情绪映射（无品牌、无素材，需从内容气质出发时）**
- **触发条件**：主题是抽象概念、研究报告、文化或公共议题。
- **具体动作**：1) 用 3 个词写目标情绪（如「可信、克制、前瞻」）；2) 映射到色相带：可信 200–250°、活力 10–40°、稳健 140–170°、警示 0–15°、中性 30–60° 低饱和；3) 定基调：浅底（L ≥ 92%）或深底（L ≤ 18%），二者只选一为主；4) 定饱和上限 0.85，正文区域再降 20%。
- **常见错误**：用「蓝色 = 专业」的单一对应关系草率定色，结果与竞品撞色；同一色相内必须再用明度差拉开层级。

**路径 D｜语义功能（页面要区分类别、正负、时序时）**
- **触发条件**：内容本身带分类、增减、先后或风险等级。
- **具体动作**：1) 数类别个数 n；n ≤ 4 用单色 + 明度阶梯（L 每级差 ≥ 12%，保证可辨）；n ≥ 5 改用位置/标签编码，不靠加色相；2) 有正负或风险，加 `ok`/`warn` 两色，其色相与 `primary` 差 ≥ 90°；3) 有时序，用同一色相的饱和度渐变，不用彩虹色。
- **常见错误**：为 7 个类别配 7 个色相，超出 `maxHuesPerDeck` 的 3 色上限，且色盲读者最多只能分辨其中 3–4 个。

## 2. 60-30-10 面积分配与取色流程

**面积计算法**：单页 100 in²。按 `color.areaShareDefault`，主色 60 in²、辅助色 30 in²、强调色 10 in²。强调色许可区间为 3%–15%（`color.accentAreaShareRange`），即 3–15 in²。

| 面积角色 | 占比 | 100 in² 页面上的面积 | 典型承载 |
|---|---|---|---|
| 主色 primary | 60% | 60 in² | 背景、满版色块、大标题底色 |
| 辅助 secondary | 30% | 30 in² | 图表主体、区块底、图片边框 |
| 强调 accent | 10%（3–15%） | 10 in²（3–15） | 关键数字、峰值、警示标记 |

**规则：面积用元素几何求和**
- **触发条件**：一页版式排定后，或验收前抽查。
- **具体动作**：把该页所有 `rect`/`image`/`polygon` 的 w × h（in²）按颜色归并，除以 100 in² 得占比；文字按 `role` 词频不参与面积统计。主色占比落在 55–65%、强调 3–15% 即达标；未被图形覆盖的部分（留白 ≥ 25%）计入主色。
- **常见错误**：强调色以细线、小圆点分散在 8 个位置，总面积 2 in²（低于 3%），读者感知不到强调；应集中成 1 个 10 in² 的块或 1 个数字。

## 3. 色彩系统输出清单

| 令牌 | 角色 | 取值约束 | 备注 |
|---|---|---|---|
| `bg` | 主背景 | 浅底 #F7F5F2–#FBF9F6；深底 #121417–#1A1E24 | 禁 #FFFFFF / #000000 |
| `bgAlt` | 次背景 | 与 `bg` 明度差 4–8% | 用于分区、卡片、表格斑马纹 |
| `primary` | 主色 | 饱和度 ≤ 0.85 | 面积 60%，决定整套气质 |
| `secondary` | 辅助色 | 与主色色相差 ≤ 60° 或互补 | 面积 30% |
| `accent` | 强调色 | 与 `secondary` 对比明显，饱和度可到 0.85 | 面积 3–15%，语义唯一 |
| `fg` | 正文色 | #1A1A1A–#262626 | 与 `bg` 对比度 ≥ 4.5:1 |
| `fgMuted` | 次文字 | 与 `bg` 对比度 ≥ 4.5:1 | 常用于 source/caption |
| `warn` / `ok` | 语义色 | 色相与主色差 ≥ 90° | 只用于风险与完成状态 |
| 图表色序 | 系列色 | ≤ 6 色，见 §6 | 按语义映射，不按出现顺序 |

**禁用组合**：纯黑文字 + 纯白底；低饱和浅灰（L > 75%）作正文；红 / 绿相邻仅靠色相区分；`accent` 用作正文颜色；同一页出现 2 个以上 `accent` 语义。

## 4. 对比度：WCAG 2.2 SC 1.4.3

**阈值**：正文 ≥ 4.5:1（`contrast.bodyText`）；大字 ≥ 3:1（`contrast.largeText`）；非文字 UI 元素（线、图标、边框）≥ 3:1（`contrast.nonTextUI`）。大字判据：≥ 18 pt 或 ≥ 14 pt 粗体（WCAG 2.2 SC 1.4.3）；本仓库 `contrast.largeTextPt` 取更严的 24 pt / 18.66 pt，按严值执行。

**公式**（WCAG 2.2 相对亮度定义）：

```
L = 0.2126·R + 0.7152·G + 0.0722·B     （R/G/B 先做 sRGB 线性化）
c = C ÷ 255；c ≤ 0.03928 时 c ÷ 12.92，否则 ((c + 0.055) ÷ 1.055)^2.4
对比度 = (L_亮 + 0.05) ÷ (L_暗 + 0.05)      范围 1:1–21:1
```

**实测色对（按上式计算，保留两位）**

| 前景 | 背景 | 对比度 | 正文 4.5:1 | 大字 3:1 | 用途判定 |
|---|---|---|---|---|---|
| #1A1A1A | #FFFFFF | 17.40:1 | 通过 | 通过 | 正文可用（白底不推荐，见 §7） |
| #4A4A4A | #FDFCFA | 8.64:1 | 通过 | 通过 | 正文可用 |
| #767676 | #FFFFFF | 4.54:1 | 通过（临界） | 通过 | 正文字色下限 |
| #8A8A8A | #FFFFFF | 3.45:1 | 不通过 | 通过 | 只能做大字或 `fgMuted` 于大字场景 |
| #5B7C99 | #EDEAE4 | 3.65:1 | 不通过 | 通过 | 只做大字标题，正文换深一档 |
| #D98E32 | #FFFFFF | 2.67:1 | 不通过 | 不通过 | 不得作文字色，只能作色块 |
| #FFFFFF | #1F3A5F | 11.48:1 | 通过 | 通过 | 深色页正文可用 |
| #FFFFFF | #B3541E | 5.00:1 | 通过 | 通过 | 警示色底 + 反白文字可用 |

**规则：先算后定色**
- **触发条件**：任何文字色 / 背景色组合进入 `tokens.colors`。
- **具体动作**：逐对代入公式；正文目标 ≥ 6:1 留余量（投影会损失亮度），最低不得低于 4.5:1；不达标时优先改 `fg` 明度（±10% 一级），不先动版式。
- **常见错误**：只测了设计稿上的 8.6:1，现场投影偏亮后实际落到 4.2:1，最后一排读不清 caption。

## 5. 深色页的使用条件

三条判据同时满足才可用深色底，否则用浅底：
1. **环境**：会场可控光（屏幕照度 ≤ 100 lux）或使用自发光 LED 屏；自然光充足的教室与展台不用。
2. **素材**：该页有暗调图片（暗部面积 ≥ 60%）或需要满版出血照片。
3. **内容**：封面、章节页、单点结论或引文页，单页字数 ≤ 60 字。

**规则：深色页受比例约束**
- **触发条件**：决定启用深色页。
- **具体动作**：深色页 ≤ 全册 25%，连续 ≤ 2 页；深色页上的 `fg` 用 #E8E4DC–#F2EFE9（#E8E4DC on #1A1E24 = 13.20:1），不用纯白；`accent` 在深底上提亮 10–15% 明度。
- **常见错误**：深色页与浅色页逐页交替，观众在第三次切换后开始看手机。

## 6. 图表色序

**规则：≤ 6 色、按语义、色盲安全**
- **触发条件**：图表系列数 1–6。
- **具体动作**：按色盲安全顺序取色（Okabe–Ito 色序，核验：2026-11）：`#0072B2` 蓝 → `#E69F00` 橙 → `#009E73` 绿 → `#CC79A7` 红紫 → `#56B4E9` 浅蓝 → `#999999` 灰。语义固定：蓝 = 本期/主指标，橙 = 对比期/次指标，绿 = 正向结果，红紫 = 负向或风险，灰 = 基准线与其它。系列 > 6 时改用直接标注 + 分组，不加色。
- **常见错误**：拿彩虹色按系列顺序上色，红绿相邻，色盲读者无法区分「增长」与「下降」两条线。

## 7. 禁用纯 #000000 / #FFFFFF

**原因**：投影设备的黑场是灰度而非绝对黑，纯黑文字在亮背景上产生光晕；纯白满版在强光下反射眩光，主观对比度反而下降；且纯黑/纯白无法再派生更暗或更亮的层级，`bgAlt` 与 `fgMuted` 失去余地。21:1 的极端反差在长时间阅读时加剧视觉疲劳。

**替代区间**：正文 `fg` 取 #1A1A1A–#262626；浅色背景 `bg` 取 #F7F5F2–#FBF9F6（需要最亮时用 #FDFDFB）；深色背景取 #121417–#1A1E24；深底文字取 #E8E4DC–#F2EFE9。

**规则：色彩令牌不得为纯黑纯白**
- **触发条件**：写入任何 hex 值。
- **具体动作**：`grep` 检查 `#000000` 与 `#FFFFFF`，命中即改；`deck.schema.json` 的 `tokens.colors` 描述已明示该禁令。对比度需要更高时，改明度差而不是取极值。
- **常见错误**：为了「保证清晰」把正文设成 #000000，投影后字边发毛，7 m 外反而更难读。

## 8. 不只靠颜色编码的四种冗余手段

1. **文字标签**：系列名或数值直接标在图上（`chart.directLabel: true`），不依赖图例记忆。
2. **形状与位置**：不同系列用不同标记形状（圆/方/三角），或固定在坐标轴上下两侧。
3. **线型与图案**：实线 / 虚线 / 点线，填充用斜纹（密度差 ≥ 2 档）。
4. **符号与数值**：▲▼●■ 表示增减方向，旁边直接给数值与单位。

**规则：任一颜色编码至少叠加一种冗余**
- **触发条件**：用颜色区分 2 个以上数据类别或状态。
- **具体动作**：至少叠加上述 1 种手段；正文与背景的色差不作为信息编码，只作层级。检查方式：把页面转灰度，若信息仍完整可读即达标。
- **常见错误**：红绿两个色块只靠颜色区分通过 / 未通过，灰度打印或色盲观众看到两个同亮度灰块。

## 9. 强调色的语义规则

四个语义槽，一色一义：**结论数值**（本页唯一结论数字）、**警示**（风险、缺口、延期）、**峰值**（数据极值）、**关键节点**（时间线里程碑）。同一语义全册同色；不同语义不得共用一色。

**规则：强调色的出现频率上限**
- **触发条件**：任何一页打算使用 `accent`。
- **具体动作**：单页强调元素 ≤ 3 处；强调面积 3%–15%（`color.accentAreaShareRange`）；不得用于装饰线、页码、栏目名；全册带强调的页面占比 ≤ 80%，即至少 20% 的页面没有强调色，否则强调失效。
- **常见错误**：每页标题、页码、图标都用强调色，观众到第 5 页就不再把它当信号。

## 检查清单

- [ ] `tokens.colors` 至少含 `bg`、`fg`、`bgAlt`、`fgMuted`、`primary`、`secondary`、`accent`。
- [ ] 全部 hex 中无 `#000000` 与 `#FFFFFF`。
- [ ] `fg` on `bg` 对比度 ≥ 4.5:1，`fgMuted` on `bg` 亦 ≥ 4.5:1。
- [ ] 非文字元素（线、图标、边框）与相邻底对比度 ≥ 3:1。
- [ ] 全册色相数 ≤ 3；主/辅/强调面积比约为 60/30/10，强调在 3%–15%。
- [ ] 单页强调元素 ≤ 3 处，且每个强调只对应 1 个语义。
- [ ] 图表系列 ≤ 6 色，顺序为蓝→橙→绿→红紫→浅蓝→灰。
- [ ] 深色页 ≤ 全册 25%，连续 ≤ 2 页，且满足环境/素材/内容三判据。
- [ ] 任一处颜色编码都叠加了标签、形状、线型或符号中至少一种。
- [ ] 页面转灰度后，所有区分信息仍可读。
