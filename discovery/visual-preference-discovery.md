# 视觉偏好探索方法

用户不懂风格名词，这不是障碍，而是默认前提。本文件把这件事实变成可执行流程：**不问风格名，只问可感知维度；每个回答都直接落成带单位的参数**。

6 个维度：构图秩序、信息密度、图像类型、情绪强度、对比强度、参考物。每维度 2–4 个可对比选项。

---

## 1. 方法总则

**R1 用维度代替风格名**

**触发条件**：需要了解用户视觉偏好。
**具体动作**：只问 6 个维度中的 2–3 个（单轮 ≤ 2 个），每个维度给二选一或三选一；不问"喜欢什么风格"，也不向用户解释设计术语。
**常见错误**：问"喜欢极简还是孟菲斯"。用户随机选一个，之后整套稿按错误的视觉系统做完。风格名只在 AI 内部使用，对用户只输出维度与参数。

**R2 一次只变一个维度**

**触发条件**：需要给用户做视觉对比。
**具体动作**：每轮只改 1 个维度，其余 5 个维度锁死在同组参数上；每轮给 2 个（最多 3 个）方案，方案用第 5 节的"三行描述"呈现。3 轮内必须收敛。
**常见错误**：一次给 4 个完整方案（颜色、字体、图片、构图全不同）。用户只能凭整体直觉选，选完说不出喜欢哪一点，无法迁移到其余 20 页。

**R3 每个偏好必须落参数**

**触发条件**：用户说出任何视觉倾向（"干净""有力量""像杂志"）。
**具体动作**：按第 5 节 5 步翻译，输出 ≥ 1 行带单位参数；无法落参数的形容词不入记录，只能作为"未采用偏好"留档。
**常见错误**：确认书「视觉偏好」栏写着"喜欢干净一点的"。执行者读完不知道留白是 25% 还是 40%，也不知道元素上限是 8 个还是 14 个。

---

## 2. 六个可感知维度

每张表的三列固定为：选项 / 用户会看到的样子 / 落到的参数。选择参数时不得超过 [thresholds.json](../schema/thresholds.json) 的硬边界。

### D1 构图秩序：规整 ↔ 自由

| 选项 | 用户会看到的样子 | 落到的参数 |
|---|---|---|
| 严格规整 | 所有元素左边缘落在同一条竖线上，页面像一张排好的表格，没有斜的、没有压边的 | 12 栏网格、元素偏移 0 in、旋转 0°、出血 0 处、页边距 0.6/0.45 in |
| 规整中带一处破格 | 整体对齐，但每 3–4 页有 1 页让一张图压过页边 | 12 栏网格 + 每 4 页允许 1 处出血 ≥ 0.5 in、旋转 0°、分栏比 2:1 |
| 自由动态 | 元素可以是斜的、可以压边、可以一大一小不对齐 | 允许 ≤ 2 处出血、1 个元素旋转 ≤ 6°、非对称分栏 3:2、焦点可放在画面外侧 1/3 线 |

### D2 信息密度：低 ↔ 高

| 选项 | 用户会看到的样子 | 落到的参数 |
|---|---|---|
| 低密度 | 一页只有一句标题和一句话，大片区域是空的 | 文本块 ≤ 2、字数 ≤ 120 字/页、留白 ≥ 40%、元素 ≤ 8、单行 ≤ 26 字 |
| 中密度 | 一页标题 + 3 段短说明，四周留一圈边 | 文本块 ≤ 3、字数 ≤ 180 字/页、留白 ≥ 30%、元素 ≤ 11 |
| 高密度 | 一页塞满 4 块内容，接近一份排过版的报告 | 文本块 ≤ 4（`density.maxTextBlocksPerSlide`）、字数 ≤ 220 字/页、留白 25–30%、元素 ≤ 14、单行 30–34 字 |

### D3 图像类型：摄影 ↔ 几何 / 插画 ↔ 纯文字

| 选项 | 用户会看到的样子 | 落到的参数 |
|---|---|---|
| 摄影主导 | 每页有一张大照片，文字压在照片上或旁边 | 图片面积 ≥ 40%、满版裁切（四周 0 in 边距）、蒙版 0 层、图注 11–14 pt |
| 几何 / 插画 | 用色块、线条、示意图讲事，照片很少 | 图片 ≤ 25%、矢量图形 ≥ 2 组、色相 ≤ 3、色块为纯色无渐变 |
| 混合 | 封面和章节页用照片，内容页用图形和文字 | 图片 20–40%，仅出现在封面 / 章节页 / 证据页 |
| 纯文字 | 没有任何照片，靠字号大小和排布区分信息 | 图片 0%、字号层级 3 级（36 / 24 / 16 pt）、可用一句大字号数字当焦点 |

### D4 情绪强度：克制 ↔ 表现

| 选项 | 用户会看到的样子 | 落到的参数 |
|---|---|---|
| 克制 | 整份稿几乎只有黑白灰，一处小面积颜色，没有动画 | 强调色面积 3–7%、饱和度 ≤ 0.45、封面 56–72 pt、字重 2 级（400/700）、动效 0 处 |
| 中等 | 有一两个颜色出现得比较明显，封面字比较大 | 强调色 8–10%、饱和度 0.45–0.6、封面 64–84 pt、字重 2 级 |
| 表现 | 封面字几乎占满屏，颜色冲，允许一页压边 | 强调色 10–15%、饱和度 0.6–0.85（`color.saturationCapNormal`）、封面 72–96 pt、允许 1 处出血 |

### D5 对比强度：柔和 ↔ 强烈

| 选项 | 用户会看到的样子 | 落到的参数 |
|---|---|---|
| 柔和 | 字是深灰不是纯黑，底色是浅灰不是纯白，边界靠色块区分不靠线 | 正文对比 4.5–7:1、正文明度与背景明度差 ≤ 25%、不用纯黑 #000000、分隔用色块差值 ≤ 8% 亮度 |
| 中等 | 标题很黑，正文深灰，靠字号拉开差距 | 正文对比 7–10:1、标题对比 ≥ 12:1、可用 1 pt 细线做分隔 |
| 强烈 | 黑底白字或白底黑字，强调色块面积明显 | 正文对比 ≥ 7:1、允许纯黑底 / 纯白字、强调色块 ≥ 1 处且面积 ≥ 6%、标题与正文字号比 ≥ 2:1 |

### D6 参考物：杂志 / 海报 / 网站 / 发布会

| 选项 | 用户会看到的样子 | 落到的参数 |
|---|---|---|
| 杂志 | 封面是一句很大的标题配一张整页图，内页分 2–3 栏排 | 封面标题 56–96 pt、内页 2–3 栏、正文 16–18 pt、章节页整页图（100% 面积） |
| 海报 | 一页只说一件事，标题巨大，图或色块压到页边 | 单页单论点、标题 96 pt、文字 ≤ 60 字/页、≥ 1 处出血、图片面积 ≥ 50% |
| 网站 | 页面顶部有横栏，内容以等宽卡片排列 | 顶栏高 0.8–1.2 in、卡片 3–4 个等宽、卡片间距 0.2 in、栅格 12 栏 |
| 发布会 | 深色底、白字、一页一个大数字或一句话 | 底色明度 ≤ 20%、单页单论点、标题 72–96 pt、图片 ≥ 50%、强调色 1 个 |

## 3. 转化映射速查

同一维度内选项互斥；跨维度组合时按第 6 节取舍。

| 维度 | 选项 → 关键参数（三选一即可，不必全记） |
|---|---|
| D1 构图秩序 | 严格规整 → 偏移 0 / 出血 0；一处破格 → 每 4 页 1 处出血；自由 → 出血 ≤ 2 处 + 旋转 ≤ 6° |
| D2 信息密度 | 低 → 120 字 + 空白 40%；中 → 180 字 + 空白 30%；高 → 220 字 + 空白 25% |
| D3 图像类型 | 摄影 → 图 ≥ 40%；几何 → 图 ≤ 25% + 图形 ≥ 2 组；纯文字 → 图 0% + 3 级字号 |
| D4 情绪强度 | 克制 → 强调色 3–7% + 饱和 ≤ 0.45；中等 → 8–10%；表现 → 10–15% + 饱和 0.6–0.85 |
| D5 对比强度 | 柔和 → 4.5–7:1 + 明度差 ≤ 25%；强烈 → ≥ 7:1 + 色块 ≥ 6% |
| D6 参考物 | 杂志 → 56–96 pt 封面 + 2–3 栏；海报 → 96 pt + 出血；网站 → 卡片 + 顶栏；发布会 → 深底 + 72–96 pt |

## 4. 一次只变一个维度的对比法

**R4 三轮对比**

**触发条件**：用户说"我说不清想要什么"或"给我几个方向看看"。
**具体动作**：按下面三轮走，每轮只动 1 个维度，用户选定后立即锁定并写入记录；3 轮结束必须收敛，不得继续加轮。
**常见错误**：把 4 个方向做成 4 页完全不同风格的稿。用户选"第 2 个"，但第 2 个同时改了颜色、字号、图片和构图，无法判断到底喜欢哪一项。

| 轮 | 锁定项 | 只变这一项 | 给几个方案 | 判据（本轮结束时必须有） |
|---|---|---|---|---|
| 1 | D1 规整、D2 中密度、D4 克制、D5 柔和 | D3 图像类型 | 2 个（摄影 / 几何） | 用户指认 1 个，记录 `[已确认] D3=摄影` |
| 2 | 第 1 轮选中的 D3 | D2 信息密度 | 2 个（低 / 高） | 用户指认 1 个，记录 `[已确认] D2=高` |
| 3 | D1、D2、D3 | D5 对比强度 | 2 个（柔和 / 强烈） | 用户指认 1 个；D4 与 D6 未定则取默认（中等 / 无） |

三轮总共 6 个方案，覆盖 6 个维度中的 4 个；剩余 2 个维度（D4、D6）在用户未表态时按默认值执行并标 `[假设]`，交付后允许改。

---

## 5. 把形容词翻译成规则的 5 步

以用户原话"像发布会那种，有力量"为例。

**第 1 步：抄原词**
把用户原句完整写进记录（不改写、不换术语）。
判据：记录里有引号包裹的原句。

**第 2 步：定位维度**
查第 2 节，找 1–2 个相关维度。"发布会" → D6；"有力量" → D4（情绪）+ D5（对比）。
判据：写出维度编号（如 `D6 参考物 = 发布会`）。

**第 3 步：落参数**
取该维度选项对应的参数行，抄成一行带单位的参数。
示例：`D6=发布会 → 底色明度 ≤ 20%、单页单论点、标题 72–96 pt、图片 ≥ 50%`。

**第 4 步：过阈值检查**
逐项对照硬边界：正文 ≥ 16 pt、正文对比 ≥ 4.5:1、单页字数 ≤ 220 字、留白 ≥ 25%、单页元素 ≤ 14 个。任一不过，退回第 3 步换同维度更保守的选项（如"强烈"退回"中等"）。
判据：5 项全部通过，且记录里写明通过。

**第 5 步：复述并标状态**
用一句话复述参数，请用户确认；用户点头记 `[已确认]`，未回应记 `[建议]`，AI 自选取值记 `[假设]`。
示例："那按发布会那种做：深底白字，一页一个论点，标题 72–96 pt。对吗？"

**R5 第 4 步不可跳过**

**触发条件**：任何形容词翻译完成后。
**具体动作**：必须跑 5 项硬边界检查，并在记录里留一行"阈值检查：5/5 通过"。
**常见错误**：用户说"字大一点"，AI 直接把标题设到 120 pt，超出封面 56–96 pt 区间，投影时四边被裁。

## 6. 用户"我全都要"时的取舍

**R6 取舍顺序**

**触发条件**：用户选中的维度组合互相冲突（如"高密度 + 摄影主导 + 克制 + 12 页以内"），或用户明确说"都要"。
**具体动作**：按下列 5 级顺序裁决，每裁决一次在记录里写 1 行"放弃：X，原因：Y"。
**常见错误**：把 4 个偏好全部塞进同一页，结果 220 字 + 图片 40% + 空白 25% 三者相加必然溢出（qa 越界容差 0.02 in）。

1. **硬阈值不让步**：正文 ≥ 16 pt、正文对比 ≥ 4.5:1、单页 ≤ 220 字、留白 ≥ 25%、单页元素 ≤ 14。任何偏好与这 5 条冲突，偏好作废。
2. **内容优先于偏好**：证据页的图表类型由数据结构决定（时间序列 → 折线；部分与整体 → 堆叠条），不受 D3 偏好覆盖。
3. **按页面角色分配偏好**：封面、章节页承载 D4 / D6（情绪与参考物）；内容页、证据页承载 D1 / D2（秩序与密度）。一套稿允许 2 种密度，但必须按段落整体切换，不得同页混用。
4. **同页冲突的降级顺序**：先删装饰元素 → 再降图片面积（每次降 10%）→ 最后降字号（下限 16 pt）。字号降到底仍放不下，就拆页。
5. **无法同时满足就交回用户**：给 2 个方案，各写 1 句代价（"方案 A：多 3 页；方案 B：图片面积从 40% 降到 25%"），让用户选，不自行折中。

## 检查清单

- [ ] 从未向用户提出"你想要什么风格"类问题，视觉问题全部来自 D1–D6
- [ ] 单轮视觉问题 ≤ 2 个维度，每维度 ≤ 3 个选项
- [ ] 每轮对比只改变 1 个维度，其余 5 个维度的参数在方案中保持一致
- [ ] 对比轮数 ≤ 3 轮，第 3 轮结束时 4 个维度已定、2 个已标默认值
- [ ] 每条视觉偏好在记录中都有 ≥ 1 行带单位参数（pt / % / 处 / 级）
- [ ] 5 项硬边界逐条检查过：16 pt、4.5:1、220 字、25% 空白、14 个元素
- [ ] 参数未超出 [thresholds.json](../schema/thresholds.json) 的区间（抽查封面 56–96 pt、强调色 3–15%）
- [ ] 冲突组合已按 5 级顺序（硬阈值 → 内容 → 页面角色 → 降级 → 交回用户）裁决并留"放弃"记录
- [ ] 未采用的偏好已写入「已记录未采用」并附 1 句原因
- [ ] 每个维度选项的描述都是"用户会看到的样子"，未出现风格专有名词
