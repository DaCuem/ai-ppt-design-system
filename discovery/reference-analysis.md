# 参考作品分析方法

用户发来一张图或一个链接说"就要这种感觉"时，不要记录这句话，也不要照搬那一页。本文件给出固定的 7 步拆解法：先把参考作品拆成**可量化的视觉事实**，再分离出**可迁移规则**与**不可照搬部分**。

拆解产物只写规则，不写"像 XX 那样"。

---

## 1. 三条前置规则

**R1 先拆后问**

**触发条件**：用户提供参考作品（图、链接、截图、旧 PPT、或"像某品牌那样"）。
**具体动作**：先按第 2 节 7 步拆完并复述 5 条结论，再问唯一一个问题："这 5 条里，哪 1–2 条必须保留？"不得先问"你喜欢它哪里"。
**常见错误**：先问"你喜欢这张图的什么"。用户答"整体感觉"，AI 得不到任何可执行信息，最后只能照着那一页画。

**R2 只迁移可量化的部分**

**触发条件**：拆解完成，准备写入视觉系统。
**具体动作**：进入视觉系统的每条规则必须含 ≥ 1 个数字与单位（pt / % / 栏 / 处 / :1）。写不出数字的观察一律降级为"不采用"，仅留在分析记录里。
**常见错误**：把"这张图很有秩序"写进视觉系统。执行者读完不知道用几栏网格、对齐到哪条线。

**R3 版权红线**

**触发条件**：参考作品来自网络、他人 PPT、商业品牌物料。
**具体动作**：只迁移规则（栏数、面积比、字号倍率、色彩角色、图文关系），不复制成品页、logo、字体文件、摄影作品、插画、文案。参考图本身不进入交付物。
**常见错误**：把参考图裁一裁当封面背景。交付后属于未授权使用他人素材，且与用户主题无关。

---

## 2. 七步拆解法

每步都给出"看什么 / 怎么估 / 记什么 / 判据"。所有比例以参考图自身画面为 100%。

### 第 1 步：视觉焦点

- **看什么**：第一眼落在哪个元素上，它占多大面积、在什么位置。
- **怎么估**：把画面按 4×4 切成 16 格，数焦点占几格；每格 = 6.25%。位置用九宫格记（左上 / 中上 / 右上 / 左中 / 中心 / 右中 / 左下 / 中下 / 右下）。
- **记什么**：`焦点类型（图/字/数字/色块）+ 面积 % + 九宫格位置 + 与次大元素的字号比`。
- **判据**：面积到 6.25% 的整数倍，位置能落到九宫格 1 格，比值写成 `x:1`。

### 第 2 步：网格与构图

- **看什么**：有几条竖直对齐线、几栏、四边边距多宽、有没有元素压出页边、整体对称还是偏一侧。
- **怎么估**：数左边缘落在同一条竖线上的元素组数 → 栏数（1/2/3/4 栏）；用画面宽度 10 等分估边距（< 5% / 5–10% / > 10%）；压边元素数逐个数。
- **记什么**：`栏数 + 边距占比 + 出血处数 + 对称/非对称 + 分栏比（如 3:2）`。
- **判据**：栏数为整数，边距落到三档，出血处数为整数。

### 第 3 步：字号层级

- **看什么**：一共几个字号层级、最大字占画面多高、标题与正文差几倍。
- **怎么估**：量汉字实高占画面高度的比例 r，字号 ≈ 600 × r（16:9、7.5 in 高画布，误差 ±10%）。速查：r = 4% → 24 pt；6% → 36 pt；8% → 48 pt；10% → 60 pt；13% → 78 pt。倍率 = 最大字号 ÷ 正文字号。
- **记什么**：`层级数（2–4）+ 各级字号 pt + 标题/正文倍率 + 行距（紧/中/松 → 1.0 / 1.3 / 1.5）`。
- **判据**：层级数 ≤ 4，字号有 pt 值，倍率写成 `x:1`。

### 第 4 步：色彩角色

- **看什么**：几个色相、各占多少面积、有没有纯黑纯白、饱和度高低。
- **怎么估**：数不同色相数（不含黑白灰）；用 16 格法估面积；饱和度分三档（低 ≤ 0.45 / 中 0.45–0.6 / 高 0.6–0.85）；记录最暗与最亮处的明度差。
- **记什么**：`色相数 + 主/辅/强调面积比（如 60/30/10）+ 是否纯黑纯白 + 饱和度档位`。
- **判据**：色相数为整数，面积比三项相加 = 100%（±5%）。

### 第 5 步：图文关系

- **看什么**：图占多大面积、文字在图内还是图旁、有没有蒙版、图是满版还是留边。
- **怎么估**：图面积用 16 格法；文字与图的位置关系归为 4 类（图上压字 / 图左文右 / 图上文下 / 图文分离）；蒙版层数（0/1/2）。
- **记什么**：`图面积 % + 图文关系类型 + 蒙版层数 + 是否满版裁切`。
- **判据**：面积到 6.25% 的整数倍，关系类型落到 4 类之一。

### 第 6 步：可迁移规则

- **看什么**：哪 3–5 条规则换一个主题仍成立（换主题后还能用）。
- **怎么估**：对每一条问"删掉品牌名和行业内容后还成立吗"，成立才可迁移。
- **记什么**：`3–5 条规则，每条 1 行，含数字与单位`。例：`标题占画面宽度 1/3；正文 2 栏、每栏 ≤ 20 字；强调色面积 6%`。
- **判据**：每条含 ≥ 1 个数字，条数 3–5 条。

### 第 7 步：不可照搬部分

- **看什么**：哪些东西一换主题就失效，或不能合法使用。
- **怎么估**：按 4 类筛查——品牌资产（logo / 专属字体 / 品牌图形）、主题专属（行业图像 / 产品照）、技术条件（3D、动效、专业修图）、文化语境（特定场合的视觉惯例）。
- **记什么**：`4 类各 0–n 条，每条写"为什么不能搬"`。
- **判据**：4 类逐类过一遍，至少写出 1 条。

| 5 | 图文关系 | 图面积：__%；关系：__；蒙版：__ 层；满版：__ |

**多张参考的合并**

| 参考编号 | 来源（用户提供 / 用户口述） | 主导维度（D1–D6） | 可迁移规则数 | 与其它参考冲突处 | 处理方式 |
|---|---|---|---|---|---|
| A | 用户上传截图 | D2 高密度、D5 强烈 | 4 | 与 B 的密度相反 | 取 B 的密度，只在章节页用 A |

## 4. 无图片能力时的文字替代法

**R4 声明先行**

**触发条件**：AI 无法展示或读取图片（纯文本环境、链接不可访问、用户只给文字描述）。
**具体动作**：第一句必须先声明"以下为文字描述，未展示真实图片"；随后用第 2 节的方法要求用户提供可量化的口头描述（"标题大概占页面高度的多少"），或直接按第 3 步的速查表让用户选一档。
**常见错误**：用"这张图很高级，我们照这个做"敷衍过去。用户以为 AI 看过，后续每页都偏离。

**文字替代三件套**

1. **九宫格 + 面积百分比**：`焦点：中心格，占 25%`——代替"焦点在中间且很大"。
2. **ASCII 线框**：用 `┌ ─ │ ┐ └ ┘ ├ ┤ ┬ ┴ ┼` 画 40–72 列宽的版式示意，标出焦点、栏数、图片区。例：

```text
┌──────────────────────────────┐
│ 标题 48 pt          [图 40%] │
│ ──────────────────────────── │
│ 正文 18 pt，2 栏，每栏 20 字 │
└──────────────────────────────┘
```

3. **三行描述**：第 1 行构图（焦点 + 栏数 + 出血处数）、第 2 行字号（标题 / 正文 / 倍率）、第 3 行图像（面积 % + 处理方式）。三行必须都能填满，任一行为空说明拆解未完成。

## 5. 版权边界

| 可迁移（规则） | 不可复制（资产） |
|---|---|
| 栏数与分栏比 | 完整成品页、版式整体照搬 |
| 字号层级与倍率 | 品牌专属字体文件 |
| 色彩角色与面积比 | logo、品牌图形、商标 |
| 图文面积关系 | 摄影作品、插画、3D 渲染图 |
| 节奏（密/疏交替） | 原文案、广告语 |

**R5 冲突时结构优先**

**触发条件**：参考作品的视觉语言与用户主题不匹配（如时尚杂志风用在工业检测报告上）。
**具体动作**：保留第 2 步（网格）、第 3 步（字号倍率）、第 6 步（可迁移规则）；替换第 4 步（色彩角色改为主题色）与第 5 步（图像改为产品照或示意图）。在记录里写 1 行"结构保留、语言替换"。
**常见错误**：整页照搬时尚杂志的满版人像，工业报告里没有可用人像，最后塞一张无关的图。

## 检查清单

- [ ] 7 步全部执行，第 1–5 步均有数字（面积 % / 栏数 / pt / 色相数 / 层数）
- [ ] 第 6 步产出 3–5 条可迁移规则，每条含 ≥ 1 个数字与单位
- [ ] 第 7 步 4 类不可照搬项逐类筛查过，至少写出 1 条
- [ ] 先拆解后提问：唯一的问题是"哪 1–2 条必须保留"
- [ ] 参考图未进入交付物；无 logo / 字体文件 / 摄影作品被复制
- [ ] 无图片能力时，首句已声明"未展示真实图片"，且有九宫格或 ASCII 线框
- [ ] 拆解结论写入视觉系统时全部含单位，未出现只有形容词的条目
- [ ] 参考作品与主题冲突时，已记录"结构保留、语言替换"及替换项
- [ ] 面积估算精度到 6.25%（16 格法），字号估算标注 ±10% 误差
- [ ] 多张参考并存时，冲突处已指定处理方式（取谁的哪个维度）
