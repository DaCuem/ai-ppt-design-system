# 需求问题库与提问分支

本文件是**可选问题池**，不是问卷。每轮从中取 ≤ 3 个问题，取哪些由用户当前状态决定（状态判定见 [conversation-guide.md](./conversation-guide.md) 第 2 节）。

问题总量 28 个，分四组。每个问题必须能回答"答 A 和答 B 会让哪个参数变"，否则删除。所有映射参数以 [thresholds.json](../schema/thresholds.json) 为准。

---

## 1. 用池规则

**R-Q1 选题规则**

**触发条件**：每轮开始。
**具体动作**：从「第一优先级」按顺序取，但先扫已知字段：首条消息已含的字段整题跳过。跨组取题时单轮 ≤ 3 个，且结构类与格式类不同轮。
**常见错误**：从第一组第 1 题开始逐题问到底。用户首条消息已说"15 分钟、给客户看"，还在问场合和受众。

**R-Q2 推断确认代替提问**

**触发条件**：答案可从用户给的材料、文件名、旧版 PPT 推断出（准确度 ≥ 80%）。
**具体动作**：用陈述句写进记录并请一句确认（"按材料看是给内部评审的，对吧"），不占用问题预算。
**常见错误**：把推断直接写成 `[已确认]`。推断错了会让整份确认书失去可信度。

**R-Q3 每题自带默认值**

**触发条件**：用户可能答不出（第三优先级尤其常见）。
**具体动作**：提问时附带默认值，格式为"问题 + 我建议 X + 不合适你说"。用户回"都行"即落 `[假设] X`，不再追问。
**常见错误**：问"你想要什么构图"，用户答"都行"，AI 再问"那规整一点还是自由一点"，两轮零信息。

**R-Q4 弃题规则**

**触发条件**：某题答 A 或答 B，页数 / 版式 / 字号 / 色彩 / 图像 / 导出格式 6 项均不变。
**具体动作**：从池中删除该题，不向用户提出；需要时记 `[假设]` 默认值。
**常见错误**：问"你们团队多少人"。答案对 16:9 的 14 页没有任何影响。

## 2. 第一优先级：目标与场景（Q1–Q7）

决定页面结构、信息量上限与页数。

| # | 问题原文 | 为什么问（影响哪个设计决策） | 典型回答 → 设计规则 / 参数 |
|---|---|---|---|
| Q1 | 这份 PPT 是有人现场讲，还是发出去让人自己看？ | 决定每页能否依赖讲解补全信息，直接改字数上限与焦点数量 | 有人讲 → 每页 1 个视觉焦点、正文 ≤ 120 字；自读 → 正文上限 220 字（`density.maxCharsPerSlide`）、每页必须自带小标题 |
| Q2 | 主要给谁看？他们对你这个主题已经了解多少？ | 决定背景铺垫页数量与术语解释密度 | 外行 → 前置概念页 ≥ 1 页、术语首次出现加中英标注；同行 → 删背景页，证据页占比 ≥ 40% |
| Q3 | 你希望他们听完做什么，或记住哪一句话？ | 决定结论句的位置、字号与是否单独成页 | 能说出 1 句 → 该句 ≤ 16 字（`type.maxCjkCharsPerLine.h1`），单独成页，40–72 pt；说不出 → 用"现状—问题—方案"结构倒推 1 句 |
| Q4 | 讲多久？ | 决定页数与每页停留时间，是后续删页的唯一依据 | 时长 T 分钟 → 页数 ≈ 1.2×T，区间 ±25%；15 min → 14 页（10–18 页）；8 min → 10 页（8–12 页）；每页停留 40–75 秒 |
| Q5 | 页数、比例、语言、格式有硬限制吗？ | 决定画布坐标系与排版模板基数 | 16:9 → 13.333×7.5 in、12 栏、栏距 0.2 in；4:3 → 10×7.5 in、10 栏；页数上限 → 按"章节页 → 重复证据页 → 过程页"顺序删 |
| Q6 | 现场投影，还是屏幕近距离看或打印？ | 决定最小字号与单行字数上限 | 投影 3–8 m → 正文 ≥ 16 pt、说明文字 ≥ 11 pt、单行 ≤ 34 字（`type.maxCjkCharsPerLine.body`）；近屏/打印 → 正文可取 16 pt 下限、单页字数上限放宽到 220 字 |
| Q7 | 什么时候要？ | 决定走标准通道还是快速通道（问题预算 12 vs 5） | ≤ 24 h → 快速通道（≤ 5 问、先给假设清单）；≥ 3 天 → 标准通道（≤ 12 问） |

## 3. 第二优先级：内容与叙事（Q8–Q14）

决定叙事骨架、证据页类型与页面数量下限。

| # | 问题原文 | 为什么问（影响哪个设计决策） | 典型回答 → 设计规则 / 参数 |
|---|---|---|---|
| Q8 | 现在手上有什么材料？文档、数据表、照片、旧 PPT、链接都算 | 决定图像面积占比与占位符数量 | ≥ 10 张可用图 → 图片面积 ≥ 40%、满版裁切；3–9 张 → 图片 20–40%、图注 11–14 pt；0 张 → 图片 0%、改用几何图形 + 文字方案 |
| Q9 | 哪些内容必须出现在里面，删了会出事？ | 决定页数下限与「必须保留」清单，是删页时的红线 | 每条必保留 ≥ 1/3 页承载；必保留 9 条 → 页数下限 ≥ 12 页，冲突时先删过程页 |
| Q10 | 最硬的一条证据是什么？数据、实验、客户案例还是引文 | 决定证据页用原生图表、截图还是引文版式 | 数据 → 原生图表、轴标签 ≥ 11 pt、数据标签 ≥ 11 pt；实验/产品 → 图 + 3 条标注；客户 → 引文 24–32 pt + 署名 |
| Q11 | 内容更偏过程、成果、论证还是观点？ | 决定叙事骨架与章节页数量 | 过程 → 时间线骨架、章节页 3–5 个；成果 → 问题—方案—结果；论证 → 论点—证据—反驳；观点 → 单页单论点 |
| Q12 | 有没有不能公开或要谨慎表述的？客户名、未发布数据、内部截图 | 决定脱敏规则，避免交付后返工或事故 | 客户名 → 写"某头部客户"；未发布数据 → 指数化（首年 = 100）；截图 → 打码或改画示意；此类内容进"不可写入交付物"清单 |
| Q13 | 有没有现成大纲？没有的话我先给一版你改 | 决定是否进入骨架共创，避免用户卡在"不知道讲什么" | 无大纲 → 先给 5 行骨架（现状/问题/方案/证据/诉求）让用户增删；有大纲 → 直接进内容审计，不再问结构 |
| Q14 | 观众最可能质疑哪一点？ | 决定是否加对照页或预置反驳页 | 有明确质疑点 → 加 1 页对照（我方 vs 替代方案，2 栏）；无 → 不加，避免自造疑问 |

## 4. 第三优先级：视觉偏好（Q15–Q21）

不问风格名，只问可感知维度。单轮 ≤ 2 个维度，映射细则见 [visual-preference-discovery.md](./visual-preference-discovery.md)。

| # | 问题原文 | 为什么问（影响哪个设计决策） | 典型回答 → 设计规则 / 参数 |
|---|---|---|---|
| Q15 | 你更想要四边对齐的规整版面，还是允许斜切、错位、非对称的版面？ | 决定网格严格度与出血、旋转的允许量 | 规整 → 12 栏严格对齐、元素偏移 0、旋转 0°、出血 0 处；自由 → 允许 ≤ 1 处出血 ≥ 0.5 in、1 个元素旋转 ≤ 6°、非对称分栏比 3:2 |
| Q16 | 一页里你希望信息少而大，还是信息多而密？ | 决定单页文本块数、字数与留白率 | 少 → 文本块 ≤ 2、字数 ≤ 120、留白 ≥ 40%、元素 ≤ 8；多 → 文本块 ≤ 4（`density.maxTextBlocksPerSlide`）、字数 ≤ 220、留白 25–30%、元素 ≤ 14 |
| Q17 | 画面里要出现真实照片，还是几何图形/示意图，或者纯文字？ | 决定图片面积占比与图像处理方式 | 摄影 → 图片面积 ≥ 40%、满版裁切、蒙版 0 层；几何/插画 → 图片 ≤ 25%、矢量图形 ≥ 2 组、色相 ≤ 3；纯文字 → 图片 0%、字号层级 3 级（36/24/16 pt） |
| Q18 | 整体情绪更克制，还是更有表现力？ | 决定强调色面积、饱和度上限与封面字号 | 克制 → 强调色 3–7%、饱和度 ≤ 0.45、封面 56–72 pt、动效 0；表现 → 强调色 10–15%、饱和度 0.6–0.85（上限 `color.saturationCapNormal`）、封面 72–96 pt |
| Q19 | 颜色关系上，要柔和的近色搭配，还是明确的强对比？ | 决定正文对比度区间与背景明度策略 | 柔和 → 正文对比 4.5–7:1、背景与正文明度差 ≤ 25%、不用纯黑；强烈 → 对比 ≥ 7:1、允许纯黑底纯白字、强调色块 ≥ 1 处且面积 ≥ 6% |
| Q20 | 有没有喜欢的杂志、海报、网站、产品发布会，或者明显讨厌的页面？ | 决定抽样哪种视觉语言，并触发参考作品 7 步拆解 | 杂志 → 大标题 + 2–3 栏正文 + 整页图；海报 → 单焦点 + 96 pt 标题 + 出血；网站 → 卡片栅格 + 顶栏；发布会 → 深色底 + 单页单论点 + 大字 |
| Q21 | 有没有明确不要的元素？圆角卡片、渐变、图标堆叠、阴影、emoji | 决定反例清单，制作时逐页排除 | 列出 ≥ 1 项 → 写入「明确不要」清单；同页同类装饰元素 0 个；违反项按 `qa.levels` 记 P2 并重排该页 |

## 5. 制作条件与素材授权（Q22–Q30）

决定交付物形态与技术可行性。可在第 3–4 轮一次性问完（≤ 3 个）。

| # | 问题原文 | 为什么问（影响哪个设计决策） | 典型回答 → 设计规则 / 参数 |
|---|---|---|---|
| Q22 | 最终要 PPTX、PDF，还是两个都要？ | 决定导出流程与字体嵌入检查 | PPTX → 原生文本框 + 原生图表；PDF → 导出前检查字体嵌入，缺字体则替换为同字宽替代字体并记录 |
| Q23 | 文字、图表、形状需要多可编辑？ | 决定元素用原生对象还是图片 | 文字/图表必须改 → 全部原生文本框与原生图表；只见效果 → 可用图片，但文字仍保留可编辑层 |
| Q24 | 你用 PowerPoint、WPS 还是 Keynote？ | 决定字体回退链与禁用特性 | 跨软件 → 字体回退链 Microsoft YaHei → Noto Sans SC → Deng；禁用 SmartArt、依赖软件的动画与 3D 效果 |
| Q25 | 有指定字体、品牌色或品牌规范吗？ | 决定字体家族数与色相数上限 | 有品牌色 → 以其为主色（面积 60%），色相总数 ≤ 3（`color.maxHuesPerDeck`）；指定字体 → 字体家族 ≤ 2；无 → 从可用字体池选 1 衬线 + 1 无衬线 |
| Q26 | 允许 AI 生成插图或示意图吗？ | 决定占位图策略与是否需要标注 | 允许 → 示意图角落标"示意图，非实拍"，字号 11 pt；不允许 → 用几何图形 + 文字替代，图片面积 0% |
| Q27 | 有版权或网络限制吗？不能用商用图、不能联网 | 决定素材来源范围与交付合规 | 有约束 → 只用本地素材 + 几何图形；外部素材必须记录来源与许可，未确认许可不入交付物 |
| Q28 | 成品给谁审、大概改几轮？ | 决定交付包内容与修订节奏 | 2 轮内 → 交付包含 QA 报告 + 修订记录；修订每轮 ≤ 40% 页面，超出则回到页面架构重排 |
> **下面两问必须在任何素材动作之前问到答复**（顺序就是：先许可 → 再工具 → 才动手）。未答复视为不许，不得先截图、先搜图、先跑生成。

| Q29 | 这次允许我做素材搜集吗（联网搜图 / 截图 / 图库检索）？ | 决定素材动作是否被授权 | 允许 → 先记来源与许可再引用；不允许 → 只用自备素材 + 几何图形；未答复 → 记为未许可，不动作 |
| Q30 | 如果允许生成图，用哪个工具或模型？有禁用的来源吗？ | 决定工具链与合规边界 | 指定工具 → 按要求执行，不可用就回报并给替代；"你看着办" → 用本机可用路径并回报；有禁用来源 → 写入黑名单，命中即换 |

## 6. 文案与语气（Q31–Q36）

两类用法：**用户已经给了文案** → 只问 Q31、Q34（他给的是原话还是要点、数字能不能动）；**用户没给文案** → 六问全问，因为它决定阶段 1.5 的整个工作方式。判定与产出见 [copywriting-patterns.md](../references/copywriting-patterns.md)、流程见 [01b_copy-production.md](../workflows/01b_copy-production.md)。

| 编号 | 问题（可直接问） | 为什么问 | 典型回答 → 动作 |
|---|---|---|---|
| Q31 | 文案是你提供，还是我按你的材料先写一版？ | 决定阶段 1.5 的来源标记（`用户原文` / `材料改写` / `从零生成`），也决定后面允许改写的程度 | 我提供 → 逐字保留，只做槽位适配；你写 → 出首稿并标 `[假设]`；材料改写 → 只摘录不新增事实 |
| Q32 | 每页标题允许我提炼成一句判断句吗，还是必须用你的原话？ | 决定 CP-08「标题非命题」的处理方式和改写权限 | 允许 → 标题写成"结论句"（如「2400 rpm 之后只换来噪声」）；不允许 → 用原话，只在 lead 里补结论 |
| Q33 | 有没有禁用词、必用词或固定称呼？（品牌名、部门名、口径） | 决定 `copy-deck.md` 头部的禁用词表，命中即改 | 有 → 全部写进禁用词/必用词表，脚本与人工各查一遍；没有 → 记"无"，不改写专有名词 |
| Q34 | 数字能不能四舍五入或改写？单位口径固定吗？ | 决定 `copy-deck.md` 的"允许改写数字"字段；这一项错会让全篇数字失去可信度 | 不能动 → 原样保留并在出处列标来源；可四舍五入 → 记录精度（如保留 1 位小数）；单位固定 → 写进口径列（℃ 不是 °C，K/W 不是 W/K） |
| Q35 | 交付前要不要先把文案稿给你审？还是直接出片？ | 决定 S6 是否阻塞等确认，以及 `[已确认]` 的来源 | 要审 → 交 `copy-deck.md` 并按 §2.5 交回合；不要 → 记"默认档：未审"，状态列写 `[假设]` 并在交付说明里点明 |
| Q36 | 你觉得现在的文案"AI 味"重吗？要不要做去 AI 味处理？ | 决定是否进 S8，以及走哪条外部路径 | 重 → 先看宿主有没有润色 skill（P1），没有就问 Q37；不确定 → 先跑 `copy_check.py` 看命中哪类特征再定；不处理 → 记录决定，不反复问 |
| Q37 | 你手上/环境里有没有已装的润色或去 AI 味 skill？（如 humanizer-zh）没有的话，允许我联网找并安装一个开源工具吗？ | 决定走 P1 还是 P2；**没许可就不许检索、下载、安装** | 有 → 记下名字，读它的说明再执行；没有且允许 → 按 `copywriting-antislop.md` §4 五条硬条件筛候选给你选；不允许 → 走 P3 换模型审校 |
| Q38 | 这份内容是未公开的吗？能不能把正文发给第三方模型或在线工具？ | 决定能否用在线/需 API 的工具，以及 P3 的交接包能不能出这个门 | 未公开且不许外发 → 只用离线可跑的工具；可以发 → P3 与需 API 的工具都放开；不确定 → 按不许外发处理 |

> **路径 P2（联网装工具）与 P3（换模型）都必须先拿到 Q37 / Q38 的答复**：
> - P2 未获许可时，检索、下载、安装三件事一件都不做（与素材授权的逻辑一致：先许可 → 再工具 → 才动手）。
> - P3 需要用户在场：把 `records/copy-crosscheck.md` 交给他，由他丢给另一个模型（qwen / gpt 等），拿回表格再合并。不要自己假装"已让第二个模型看过"。

## 7. 裸问法改写对照

这些问法必须改写后再发。左列禁止原样使用。

| 裸问法（禁用） | 改写后的可感知问法 | 改写理由 |
|---|---|---|
| 你想要什么风格？ | 你更想要四边对齐的规整版面，还是允许斜切错位的版面？（Q15） | 用户不掌握风格名词，但能判断两种版面的差别 |
| 你喜欢什么颜色？ | 主色用你们品牌色，还是我从素材里取一个？ | 前者可执行，后者是开放色相选择，无法收敛 |
| 要不要做得高级一点？ | 每页元素压到 ≤ 8 个、留白 ≥ 40%，还是保持现在的信息量？ | 把不可判定的形容词换成元素数与面积占比 |
| 你喜欢什么排版？ | 标题压在图片左上角，还是单独一行放在正文上方？ | 用户能比较两个具体位置，不能比较"排版" |
| 要不要加图表？ | 这条数据用柱状图对比，还是用一句 40 pt 的结论讲？ | 问题变成"呈现方式二选一"，答案直接落参数 |
| 受众是谁？ | 台下是同部门同事、跨部门同事，还是外部客户？ | 开放式问题收不到可用于定密度的答案，选项可 |

## 8. 提问序列模板

**标准通道（12 个问题，4 轮）**

| 轮次 | 取题 | 数量 | 轮末动作 |
|---|---|---|---|
| 第 1 轮 | Q1、Q2、Q3 | 3 | 复述场景与目的，写 T1 小结 |
| 第 2 轮 | Q4、Q5、Q9 | 3 | 定页数与必保留清单，给出骨架草案 |
| 第 3 轮 | Q10、Q15、Q16 | 3 | 定证据页类型与两个视觉维度 |
| 第 4 轮 | Q22、Q24、Q25 | 3 | 定交付条件，生成需求确认书 |

**快速通道（5 个问题，2 轮）**

| 轮次 | 取题 | 数量 | 轮末动作 |
|---|---|---|---|
| 第 1 轮 | Q1、Q4、Q3 | 3 | 给 5 条假设清单让用户划错 |
| 第 2 轮 | Q8、Q22 | 2 | 直接出需求确认书，标 `[假设]` |

**R-Q5 序列可跳不可乱**

**触发条件**：用户主动提供了某轮全部答案。
**具体动作**：整轮跳过，把问题预算让给下一轮；跳过后在记录里写"第 n 轮由用户主动提供"。组内顺序可跳，组间顺序不可颠倒（必须先目标、后形式、最后格式）。
**常见错误**：因为用户先问了导出格式，就先把制作条件问完再问场景。
