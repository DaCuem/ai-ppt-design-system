# 案例 B：创意提案 · 夜航 NIGHTWAVE 音乐节视觉系统

9 页创意提案稿，用于验证同一份 `schema/deck.schema.json` 在**纯黑底 + 单一高饱和强调色 + 图片主导**的体系下仍能通过全部 30 项检查，并与 [`demo/`](../../../demo/README.md) 的纸感浅色、[工程评审案例](../engineering-review/README.md)的深蓝等宽体系形成第三套对照。

> 案例内容为演示用途的虚构样本，数字不对应任何真实项目。

## 一、受众与场合

| 项 | 内容 |
|---|---|
| 受众 | 音乐节主理人 2 人、主办方市场 2 人、场地与制作 1 人，共 5 人围桌看稿 |
| 场合 | 提案会第 2 轮：一台 27 in 显示器 + 一份 A3 打样夹，不做投屏 |
| 时长 | 15 分钟讲 + 20 分钟改稿讨论；9 页对应约 1.7 分钟/页 |
| 目的 | 从 3 个视觉方向里选中 1 个，进入 W2 的招贴与票面制作 |
| 交付 | `build/deck.pptx`，另附 A3 打样（本案例不含） |

## 二、风格选择理由

| 决策 | 理由 |
|---|---|
| 纯黑 `#080808` + 单一强调色 `#FF3D2E` | 提案对象是夜间音乐节；一色系统让招贴、票面、导视共用一套印色，成本与识别度同时受控 |
| 封面标题 96 pt、NIGHTWAVE 占 10.6 in | 画面宽度 13.333 in 的 79%，超过「≥1/2 页宽」的最低线；近看是一行字，3 m 外是一块色 |
| 字体 3 族：衬线标题 + 无衬线正文 + 等宽编号 | 衬线（Source Han Serif SC）承担标题，笔画方、重心稳；等宽只用于页码与编号，数量控制在页内 ≤2 处 |
| s06 整页翻成纸底 `#F2EFE6` | 黑色连排 5 页后翻一页纸色，读者会停一下；这一页正好是「标题选哪版」的对比页，停顿服务于判断 |
| 图片主导页 2 页（s03 满版、s05 三联） | 提案要让客户先看到「像不像」，再听解释；s03 满版只压 1 行标题 + 1 行说明，字不抢图 |

## 五、诚实限制

- **源文件来源**：本案例的 `source/deck.json` 于 2026-11-14 由 `build/deck.pptx` 逆向重建（版式签名、角色、字号阶梯按本 README 的节奏表逐页还原），与最初手写版本不保证逐字节相同；`build/deck.pptx` 已随之重建，预览图与 QA 报告为重建后的实测结果。

- **案例内容为演示用途的虚构样本，数字不对应任何真实项目**。NIGHTWAVE、4800 张票、12 组艺人、档期与报价均为示意值。
- 4 张图全部由 PIL 用几何图元现画（圆、弧、网点、矩形），不是真实设计作品，也不可能呈现真实印刷品（网点、套印、纸张纹理在屏幕上只是近似）。
- 图内文字（`NIGHTWAVE / KEY VISUAL 01`、`WORK A/B/C`）是**烧进图片像素**的，不是可编辑文本；改字必须重跑生成脚本。
- 只验证了 LibreOffice 渲染；PPT 内嵌图为 JPEG（质量 92、subsampling 0），PowerPoint 中的色彩管理与打印机 ICC 差异未验证。
- 满版图用 `zRole: bgDecor` 放在画布外沿 0 坐标，会参与打印出血，但不会计入留白统计；这意味着 `qa_check.py` 不会因为「图太大」而报警，需人工判断图是否压住信息。
- 深底投影到纸底页（s06）时亮度跳变明显，若改为全黑连排会丢失这次停顿；两种做法各有代价，本案例选了前者。

## 六、复用给下一个创意提案的三条约束

**约束 1：封面主标题先量宽度，再定字号**

**触发条件**：封面标题要在 3 m 外可读，且用户要求「标题占页宽一半以上」。
**具体动作**：先按 96 pt 量出目标行宽（西文按 0.72 em/字估算，中文按 1 em），宽度不足 6.67 in（页宽一半）就把字号往上加一档，而不是加字。
**常见错误**：先用 64 pt 排完再回头补字，结果标题只占 4.2 in，远看像副标题。

**约束 2：一色系统里，强调色只给「要读者做动作」的地方**

**触发条件**：全 deck 只用 1 个强调色，且强调色面积需控制在 3–15%。
**具体动作**：强调色只用在结论行、被选中的样本、页码以外的编号；装饰性色块一律用中性色。
**常见错误**：每页都撒一点朱红做装饰，读者不再把红色读成「重点」，强调色退化为主色的噪声。

**约束 3：满版图上的文字，先确认图的人身安全区**

**触发条件**：`image` 以 `zRole: bgDecor` 满版铺底，上面还要压标题。
**具体动作**：在图上留出至少 1/4 画面的低对比区（本案例是下方网点渐隐带）再放字；标题下沿与图内已有文字保持 ≥0.3 in。
**常见错误**：把标题压在图的中间调上，白字与浅色网点对比度降到 2:1 以下，投影后整行消失。
