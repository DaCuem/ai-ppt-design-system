# 示例三：8 页 deck 的节奏表

演示对象是 `demo/` 里那份已跑通 8 页旗舰示例（`demo/source/deck.json`，29,773 字节；`demo/build/qa.md` 的汇总行是 `P0=0 P1=0 P2=0 P3=0`）。节奏表要回答一个问题：**把 8 页摊在桌上，读者在哪里停、在哪里赶、在哪里被按下去。**

先看两条口径，后面的数字都用它们：

- `元素` = 该页 `elements` 数组长度（上限 14，见 `density.maxElementsPerSlide`）。
- `ws` = 元素包围盒并集之外的空白占比，`qa_check.py` 的 DEN-05 口径（0.1 in 栅格、排除 `zRole=bg/bgDecor`、画布 13.333 × 7.5 in），下限 25%。
- `ink` = 渲染图（`demo/build/preview/page-XXXX.png`，1920 × 1081）里非底色像素占比，每 2 px 抽样、阈值 20/255，底色 `#F5F2EA`。
- `字数` = 该页所有 text 元素的字符数（含 caption / source，与 DEN-04 的 220 上限同口径）。

## 一、节奏表

| 页 | layout | 版式签名（layout + gridTemplate + focal） | 焦点位置 | 视觉密度（元素 / 文本块 / 字数） | ink | ws | 与前页的对比方式 |
|---|---|---|---|---|---|---|---|
| s01 封面 | cover | cover + full-bleed-left + ml | 左中 | **9** / 3 / 130 | 8.58% | 55.9% | —（开场；满版色块定调，全 deck 元素数第 2 高） |
| s02 陈述 | statement | statement + single-statement + ml | 左中 | **6** / 2 / **59** | 5.24% | **71.0%** | 元素 −3、字数 −71、ws +15.1 个百分点：从满版怼到单句，一次"急停" |
| s03 三 KPI | data-focus | data-focus + 3-col-kpi + **bc** | 中下 | **10** / 4 / **205** | 7.44% | 45.4% | 焦点 ml→bc、元素 +4、字数 +146：从一句话跳到三个数字 + 三句说明 |
| s04 对照表 | comparison | comparison + 5-5-split + **mc** | 正中 | **5** / 1 / 46（表内另 156） | **12.87%** | 38.9% | 元素 −5（全 deck 最少）、ink +73%（7.44→12.87）：一句话换成一张 5 行 3 列表，用面积换密度 |
| s05 流程 | process | process + single-column-list + **tl** | 左上 | 6 / 4 / 212 | 7.00% | 49.7% | 横向表格转纵向八阶段清单、焦点回左上、文本块 1→4：读法从"比对"改成"按序" |
| s06 图片证据 | evidence | evidence + image-7-4-split + ml | 左中 | 6 / **2** / 180 | 7.77% | **38.0%** | 文本块 4→2、字数 −32，介质从字换成图；ws 全 deck 最低（38.0%）但阅读负荷下降 |
| s07 编辑式 | editorial | editorial + 5-6-asym-split + mc | 正中 | 6 / 3 / **245** | 5.91% | 40.6% | 焦点 ml→mc、字数 +65（全 deck 最高）：一页讲完视觉系统的三条规则 |
| s08 收尾 | closing | closing + full-bleed-left + ml | 左中 | **8** / 3 / 223 | 5.71% | 58.2% | 回到封面同构（ml + 满版），ws +17.6 个百分点收干净 |

八页的 ink 曲线（1 个 █ ≈ 1 个百分点，按页序从上往下）：

```
s01 封面    ████████ 8.58
s02 陈述    █████ 5.24      ← 全 deck 最低
s03 三 KPI  ███████ 7.44
s04 对照表  ████████████ 12.87   ← 全 deck 最高
s05 流程    ███████ 7.00
s06 图片    ████████ 7.77
s07 编辑式  █████ 5.91
s08 收尾    █████ 5.71
```

曲线两端低、中间高，第 4 页是唯一尖峰。真正的节奏不是 ink 高低，是**每页要求读者做的动作**在换：读一句 → 扫三个数 → 比一张表 → 跟一条顺序 → 看一张图 → 读三条规则 → 执行一行命令。相邻两页没有一次动作重复，载体（字 / 数字 / 表 / 清单 / 图 / 字 / 命令）每两页换一次。

## 二、三条判读规则

**规则 1：相邻页至少换掉签名三元组中的一项**

**触发条件**：排完版式后检查相邻两页。
**具体动作**：比对 `layout + gridTemplate + focalPosition`（`schema/thresholds.json` 的 `repetition.signatureFields`）。本 deck 8 页签名全不同；s01 与 s08 签名相同，但隔了 6 页，`maxSameLayoutShare = 0.35` 也过（同签名 2/8 = 25%）。
**常见错误**：靠"同一 layout 换个标题"凑页数，REP-01 只会在**相邻**页报警，隔页重复要靠 REP-02 的 35% 上限兜。

**规则 2：密后必须给一次介质切换，不是给一次留白**

**触发条件**：某页字数 ≥ 200 或元素数 ≥ 8。
**具体动作**：下一页把文本块数降到 ≤ 2，或把载体从字换成图/表/数字。s05（212 字、4 文本块）之后接 s06（180 字、2 文本块 + 1 张图），ws 反而从 49.7% 降到 38.0% —— **空白占比不是节奏指标**，介质切换才是。
**常见错误**：以为"留白就是换气"，把密页后面接一页 70% 空白的单句，读者刚进入状态就被打断。s02 的 71.0% 空白之所以成立，是因为它在封面之后，承担的是"定场"不是"换气"。

**规则 3：焦点位置不许连续三页同向**

**触发条件**：连续三页的 `focalPosition` 相同（`none` / `full` 除外）。
**具体动作**：本 deck 的焦点序列是 ml → ml → bc → mc → tl → ml → mc → ml，最长同向是开头的 2 页（cover 与 statement 都在左侧，但一页是满版色块、一页是单句，视觉重量差 3.3 个百分点 ink）。三页同向时必须改一页的 gridTemplate 或焦点。
**常见错误**：全部页 `focalPosition: mc` 求稳，读者眼睛钉在正中，翻页只有文字在变，节奏感消失。

## 三、第 3 页为什么不放在第 1 页后面

s02 是一句话：59 个字，71.0% 空白，ink 5.24%，全 deck 最轻。它放在封面之后，作用是把满版色块"关掉"，让读者的注意力从视觉回到句子。

s03 紧接着给出三个数（1.204 / 4.5:1 / 25%）、205 个字、10 个元素，元素数全 deck 最高。**它不是"接着讲"，是"把 s02 那句话拆开算账"**：

1. **命题同一**：s02 说的是"模型缺的是可核对的约束"，s03 给的是"约束长什么样"——三条能写进 schema 的阈值（1.204 / 4.5:1 / 25%）。两句之间不需要过渡句：同一命题从定性转定量，读者不会掉线。
2. **注意力换了通道**：s02 让眼睛做"读句"，s03 让眼睛做"扫数"（1.204 是算出来的行盒比，4.5:1 是颜色对比度，25% 是留白下限）。同一个主题换通道，比换主题有效率——这就是"密"能被接受的原因：读者没被要求同时理解新概念。
3. **焦点从 ml 挪到 bc**：s02 的单句在左中（阅读起点），s03 的三个数字压在底中（KPI 行的自然落点）。焦点下移一行、右移一列，翻页时眼睛有一次真实位移，而不是原地重读。
4. **空白从 71.0% 掉到 45.4%**：这是全 deck 最大的一次密度跃迁（−25.6 个百分点）。跃迁放在第 2→3 页最安全，此时读者注意力最集中；放到第 6 页就会崩。

反过来说，如果把 s03 提到第 2 页（封面后直接上三 KPI），读者在还不知道"为什么要有这三个数"的时候就被塞进 205 个字，第三个 KPI 会被读成装饰。

## 四、第 6 页为什么是"密后疏"

s05 是八阶段流程：212 字、4 个文本块、单列清单，读者必须从头按顺序读，眼睛在纵向来回扫。这是全 deck 阅读负荷最高的一页（不是 ink 最高，是**动作最连续**）。

s06 把载体换成一张图 + 两段短文字（180 字、2 文本块）：

- **文本块 4 → 2**：读者的"起读次数"减半。流程页要读 4 次（每一步都要重新定位行首），证据页只读 2 次（图注 + 一句结论）。
- **字数 212 → 180**：降幅 15%，不算大。真正的减负来自"图不需要逐字读"——图是先看后读，文字是先读后想，两种负荷不能相加。
- **ws 反而降到 38.0%**（全 deck 最低）：图占掉了版面，空白变少。如果按"留白多 = 疏"来判断，s06 会被误判成密页。**这就是为什么节奏必须看介质和文本块数，不能只看空白。**
- **焦点 ml 保持不变，元素构成换了**：s05 是 4 个文本块（标题 + 八阶段 + 门槛句）；s06 是 1 张图 + 2 个文本块 + 一行出处。同样的焦点位置，第一动作从"读"变成"看"。

一句话：s06 的"疏"是**认知上的疏**，不是版面上的疏。换介质比删字更有效——删字会让页面变空，换介质会让页面变轻。

## 五、这份 deck 仍有一处节奏弱点

按 `schema/thresholds.json` 的 `rhythm` 段，这份 deck 有两条约束：`maxConsecutiveDenseSlides = 2`（连续密页不超过 2）与 `minVisualBreakEvery = 4`（每 4 页至少一次视觉换气）。**这两条目前没有代码实现**：`scripts/qa_check.py` 里 grep `rhythm` / `Dense` / `minVisualBreak` 都不命中，REP-01/02/03 只查签名三元组。所以 `qa.md` 全 0 不代表节奏合格，这一节只能人工判；schema 也没给"密"的判定口径，下面用两个自定义但可复算的口径。

两个可复算口径各判一次：

| 判据 | 口径 | 命中页 | 结论 |
|---|---|---|---|
| 连续密页 | 可见字数 ≥ 180（含表内文字；DEN-04 只算 text 元素，这里补上表格）且 ws < 50% | s03 / s04 / s05 / s06 / s07（s04 = 46 + 表内 156 = 202；s08 的 ws 58.2% 出局） | **连续 5 页**，上限 2 → 超 3 页 |
| 视觉换气间隔 | ws ≥ 55% 视为换气页 | s01 / s02 / s08 | s02 到 s08 之间隔 **5 页**（s03–s07），上限 4 → 超 1 页 |

两条都指向同一个位置：**s03–s07 这 5 页没有任何一页把读者从"读字"里放出来**。s06 换了介质算一次半换气（文本块降到 2），但 ws 38.0% 说明页面被图填满，眼睛仍然在密集信息里；s04 的 ink 12.87% 是全 deck 最高，一张满宽表格压在正中。

### 改法（不删页）

三个动作任选一个，都能把间隔压回 4 页以内。**下面目标值按 qa 口径估算，实际值需改完重跑 `qa_check.py` 再填**：

1. **把 s05 从八阶段砍到六阶段**：删掉 2 个阶段与末尾门槛句，字数 212 → 约 150，文本块 4 → 3。目标 ws ≥ 55%（当前 49.7%）。这样 s02 → s05 之间只剩 s03、s04 两页，换气间隔回到 3 页，s05 自己也变成换气页。
2. **在 s04 与 s05 之间插一页 L03 单点陈述**（例如"八阶段里只有两阶段决定质量"），单句页的 ws 通常在 65%–72%（s02 实测 71.0%）。deck 变 9 页，换气页落在第 5 页，两条约束同时满足。代价是多 55 秒，总时长需重排。
3. **把 s07 的 245 字拆成两页**：s07 是编辑式非对称两栏（5-6-split），字数全 deck 最高；拆成一页讲色彩与字体、一页讲网格，新增页用 statement，ws 天然 ≥ 60%。代价是 245 字被摊薄，需在讲稿里补连接句。

三个改法里 **1 最省事**（只改一页），**2 最稳**（单句页的 ws 实测最可靠），**3 对叙事最伤**（编辑式两栏是这份 deck 唯一的"体系页"，拆开就没有体系感了）。

如果什么都不改，就要在讲稿里补一次口头换气：讲到 s06 时把节奏放慢、先说图再看文字。这不是版式解法，是把节奏问题转嫁给演讲者——能用，但要写进备注。

## 检查清单

- [ ] 节奏表 8 行齐全，每行都有 layout / 签名三元组 / 焦点 / 元素数 / 与前页的对比方式
- [ ] 密度用至少两个口径（元素数 + 字数或 ink），只用一个口径的表格不通过
- [ ] 每页的"对比方式"写成差值（元素 ±n、字数 ±n、ws ±n 个百分点），不写"更密""更疏"
- [ ] 相邻页签名三元组无重复；隔页重复时核过 `maxSameLayoutShare`（本 deck 25% ≤ 35%）
- [ ] 解释"为什么这页放在这页后面"时，给出命题关系 + 焦点位移 + 密度跃迁三个量
- [ ] 指出节奏弱点时，同时给判据、命中页、上限与超出量（本 deck：连续 5 页 vs 上限 2）
- [ ] 明确写出哪些约束**没有代码实现**（`maxConsecutiveDenseSlides`、`minVisualBreakEvery` 无对应检查）
- [ ] 改法给 2–3 个选项并写清代价（页数、时长、叙事损失），不只给一个方案
- [ ] 改法里的目标值是改动目标而非实测值，注明"需改完重跑"
- [ ] 文中禁用词 0 处
