# 阶段 0 工作流：需求探索与确认

本工作流把一句模糊需求变成一份可执行、可复核的需求确认书。它只做一件事：**在动手做页之前，把会影响设计决策的未知项变成已知值或显式假设**。

时间预算：5 轮对话 / ≤ 12 个问题 / 约 15 分钟。产物 1 个文件：`requirement-summary.md`。

---

## 1. 输入

| 输入 | 必需 | 缺失时怎么办 |
|---|---|---|
| 用户首条消息（主题 + 任何已知信息） | 是 | 无首条消息则不启动，先请用户说主题（1 句话即可） |
| 用户材料（文档、数据、图、旧 PPT、链接） | 否 | 记"未提供"，触发素材缺口分支（第 6 节） |
| 已有项目记录（如二次修改） | 否 | 新建记录；若已有确认书，先读再决定是否重走 |
| 能力基线（能否生成 PPTX、能否渲染复核） | 是 | 见 [environment-report.md](../docs/environment-report.md) 结论摘要 |
| 阈值表（字号 / 密度 / 对比度 / 网格） | 是 | 见 [thresholds.json](../schema/thresholds.json)；对话中引用的数字必须与之同源 |

## 2. 前置条件

- 已读 [conversation-guide.md](../discovery/conversation-guide.md)（对话节奏与收敛判据）、[requirement-question-bank.md](../discovery/requirement-question-bank.md)（问题池）、[visual-preference-discovery.md](../discovery/visual-preference-discovery.md)（6 维度与映射）、[reference-analysis.md](../discovery/reference-analysis.md)（7 步拆解）、[requirement-summary.md](../discovery/requirement-summary.md)（三类记录与冲突分级）。
- 已知当前环境能做什么、不能做什么；不能做的能力不得在对话中承诺（承诺句必须含数字与单位）。
- 用户在线，且能接收 ≤ 12 个问题、≤ 5 轮往返。
- 工作目录已确定，确认书可落盘。

---

## 3. 操作步骤

每步都必须留下可判定的痕迹（字段值、编号或一句记录）。判据不满足不得进入下一步。

**S0 读取上下文**

动作：读用户首条消息；抽取已知字段（主题、场景、受众、时长、页数、格式、素材）；读能力基线的结论摘要；确认工作目录。
判据：记录中「已知字段」≥ 3 项；能回答"本机能否生成可编辑 PPTX 并渲染复核"（是 / 否）。

**S0b 素材授权预判（早于任何素材动作，也早于 S1 落盘）**

动作：在还没动手做任何图片/素材之前，先问三件事并等答复——① 允许素材搜集吗（联网搜图、截图、下载、图库检索）；② 允许 AI 生成图吗，用**哪个工具/模型**；③ 有禁用来源吗（竞品截图、客户未授权照片、不能联网）。把答复写进 `requirement-summary.md` 的「素材授权」区块（字段见 [templates/requirement-summary.md](../templates/requirement-summary.md)）。
判据：三件事各有**显式答复**（允许 / 不允许 / 指定工具名）；**未答复一律记为「未许可」，后续只走几何图形与留白**，不得先斩后奏。提问必须**交回合**：一条回复内给出「已做 / 要你答 / 不回则默认」三行后结束本轮（对话回合制，用户不结束你的回合就无法回话）。若用户在别处已说明（例："图我自己给"），把原话抄进该区块即可，不重复问。
规则细节见 [imagery-guide.md](../references/imagery-guide.md) §5.0。

**S1 建立需求记录**

动作：用 [templates/requirement-summary.md](../templates/requirement-summary.md) 建 `requirement-summary.md`，填入已知字段，未知字段写"未提供"（不留空冒号）。
判据：文件落盘；6 个一级区块齐全（基础需求 / 内容需求 / 视觉偏好 / 素材与制作条件 / 决策记录 / 初步建议）；无空字段。

**S2 状态判定与通道选择**

动作：对照 [conversation-guide.md](../discovery/conversation-guide.md) 第 2 节 12 种状态，定位 1 行；按"交付时间"选通道（≤ 24 h → 快速通道 5 问；否则标准通道 12 问）。
判据：记录首行写 `状态：第 n 行 / 通道：标准 / 预算：12 个问题`。

**S3 第 1 轮：目标与场景（Q1–Q3）**

动作：按问题池取 Q1、Q2、Q3，已知的跳过；收到回答后写记录并用 T1 句式小结。
判据：场景 / 受众 / 目的三字段有值，或其中 `[假设]` ≤ 1 条。

**S4 第 2 轮：内容与证据（Q4、Q5、Q9、Q10）**

动作：问时长、硬限制、必保留内容、最强证据；按 `页数 ≈ 1.2 × 时长（分钟）± 25%` 算出页数区间，四舍五入到整数页。
判据：页数区间已写出（含"页"单位）；「必须保留」≥ 3 条；证据 ≥ 1 条并标明类型（数据 / 图 / 引文 / 案例）。

**S5 内容骨架（仅当用户无大纲）**

动作：给 5 行骨架（现状 / 问题 / 方案 / 证据 / 诉求），请用户增删，最多 2 轮。
判据：骨架 ≥ 3 段有效，且用户至少改动 1 处或明确说"就这样"。

**S6 视觉维度扫描（2 个维度）**

动作：按 [visual-preference-discovery.md](../discovery/visual-preference-discovery.md) 第 2 节，取 2 个维度各给二选一 / 三选一；对回答跑"5 步翻译"；跑 5 项硬边界检查（16 pt / 4.5:1 / 220 字 / 25% 空白 / 14 个元素）。
判据：≥ 2 个维度写入 `[已确认]` 参数，或 1 个视觉方向含 ≥ 3 个带单位参数；阈值检查记录"5/5 通过"。

**S7 参考作品拆解（仅当用户提供参考）**

动作：按 [reference-analysis.md](../discovery/reference-analysis.md) 7 步拆解，复述 5 条结论，只问 1 个问题："哪 1–2 条必须保留"。
判据：可迁移规则 3–5 条且每条含数字；「不可照搬」≥ 1 条；参考图未进入交付物。

**S8 制作条件（Q22、Q24、Q25）**

动作：问输出格式、演示软件、字体与品牌规范；填素材清单（已有 / 缺失 / 允许生成）。
判据：3 项均有值；缺失素材已给出替代方案（几何图形 / 文字 / 待补清单）。

**S9 冲突检查与分级**

动作：按 [requirement-summary.md](../discovery/requirement-summary.md) 第 4 节逐条筛查；阻断级停下来请用户裁决；可延后级取默认值 + `[假设]`。
判据：阻断项 0 条未决；可延后项均标 `[假设]` 且写了替代方案。

**S10 生成并展示确认书**

动作：按模板生成确认书，用 T4 句式展示（"n 条已确认 / m 条建议 / k 条假设，回'确认'或指出编号"），等待显式回复。
判据：用户回"确认"或指出编号；未回复则停在 S10，不得开始制作。被指出编号时回对应步骤，往返 ≤ 2 次。

**S11 交接阶段 1**

动作：输出确认书 v1；记录末尾写 `已用问题 n/12`；把素材缺口与待确认项移交给内容收集与审计阶段。
判据：确认书已获确认；待确认项 ≤ 5 条且各有默认值；四类输出（记录 / 授权卡 / 参考拆解 / 素材清单）齐全。

---

## 4. 判断与分支

| 情形 | 处理 | 退出条件 |
|---|---|---|
| 首条消息已含场景 / 受众 / 目的 | 跳过 S3，直接 S4 | C1 已满足（`[假设]` ≤ 1） |
| 用户只有主题、无大纲 | S4 → S5 → S6 | 骨架 ≥ 3 段有效 |
| 用户提供参考图 / 链接 | S6 后插入 S7 | 可迁移规则 3–5 条 |
| 用户说"你定 / 看着办" | S2 后建授权卡，S6 简化为 1 个维度 | 授权卡 5 项填满，四类内容未被覆盖 |
| 用户赶时间（≤ 24 h） | 快速通道：S3 + S4 合并为 3 问，跳过 S5、S7 | 问题数 ≤ 5，5 条假设清单已确认 |
| 需求互相冲突 | S9 阻断，回冲突对应的步骤 | 用户已选出方案 A 或 B |
| 用户中途改主意 | 回 S4 或 S6，重走 S9–S10 | 确认书升版 v2 并重新确认 |
| 用户直接给整份材料 | S4 改为生成审计清单（必保留 / 可删 / 缺证据） | 清单 ≥ 3 条且用户扫过 |

**R1 每步必留痕**

**触发条件**：任一步骤结束。
**具体动作**：在记录里写下该步的判据结果（数值、编号或一句话），无痕迹视为未执行。
**常见错误**：心里判断"差不多够了"就往下走，两轮后无法回答"页数是怎么来的"。

**R2 不跨步预定稿**

**触发条件**：S10 之前的任何时刻。
**具体动作**：不得生成页面、不得承诺风格、不得开始排版；需要给用户看东西时，只给文字描述或线框（40–72 列 ASCII）。
**常见错误**：为了"让用户有感觉"，在需求未确认时先做 3 页样张。样张一定基于未确认的假设，用户一看就以为方向已定。

## 5. 输出文件

| 输出 | 位置 | 内容要求 |
|---|---|---|
| 需求确认书 | `discovery/requirement-summary.md`（项目内按模板生成） | 6 个区块齐全，每条带标签与来源，≤ 1 页 |
| 授权卡 | 确认书「决策记录」栏 | 授权原话、范围、时间、可推翻项、不可推翻项 5 项 |
| 参考拆解记录 | 确认书「参考作品及可迁移特征」栏 | 7 步结论压缩为 3–5 条可迁移规则 |
| 素材清单 | 确认书「素材与制作条件」栏 | 已有 / 缺失 / 允许生成三分类，每项说清替代方案 |
| 对话统计 | 确认书末尾 | `已用问题 n/12 / 轮次 m` |

## 6. 完成标准

全部满足才算阶段 0 完成；任一条不满足，只回到对应步骤，不重开全局。

1. **C1**：场景 / 受众 / 目的三字段有值，`[假设]` ≤ 1 条。
2. **C2**：必保留 ≥ 3 条，且 ≥ 1 条证据；页数区间已按 `1.2 × 时长 ± 25%` 算出。
3. **C3**：6 维度中 ≥ 2 个有 `[已确认]` 参数，或 1 个视觉方向含 ≥ 3 个带单位参数；阈值检查 5/5。
4. **C4**：输出格式、可编辑程度、字体与许可状态 3 项有值；素材清单三分类完成。
5. **C5**：三类记录非空；待确认 ≤ 5 条且各有默认值；阻断冲突 0 条。
6. **C6**：素材授权三问（可否搜集 / 可否生成 / 指定工具与禁用来源）有显式答复并写入「素材授权」区块；未答复时该区块写「未许可」，且后续素材动作数为 0。
7. **G1（门禁）**：用户已显式回复"确认"，或已签授权卡；C6 未满足时门禁不放行（可以在 C6 为「未许可」时继续阶段 1–4 的不含素材部分，但阶段 5 画图前必须先补 C6）。

## 7. 失败与降级

| 情况 | 处理 | 记录标记 |
|---|---|---|
| 用户不回答某字段 | 第 2 次追问后停止，取默认值 | `[假设]` |
| 用户拒绝看确认书 | 降级为授权卡 + 3 条口头约定 | `授权（未签署确认书）` |
| 材料无法读取（扫描件 / 加密 PDF / 打不开的链接） | 请用户导出文本或截图；不得根据文件名猜内容 | `素材待提供` |
| 素材全缺 | 图片面积 0%，改几何 + 文字方案，列待补素材清单 | `待补素材 n 项` |
| 能力不足（无法生成 PPTX / 无法渲染） | 按 [environment-report.md](../docs/environment-report.md) 降级路径说明，明确告知限制 | `能力限制：__` |
| 需求反复变更 ≥ 3 次 | 冻结当前版本，按最后一版重写确认书 | `v(n)` |
| 用户超过 24 h 无回复 | 不开始制作，只继续补素材清单 | `等待确认` |
| 用户要求跳过探索直接出片 | 声明 3 条默认（比例 / 页数 / 视觉方向），一次性确认 | `跳过探索（授权）` |

## 检查清单

- [ ] S0–S11 每步都有判据痕迹（字段值 / 编号 / 一句话）
- [ ] 问题总数 ≤ 12（快速通道 ≤ 5），记录末尾有 `已用问题 n/12`
- [ ] 单轮问题 ≤ 3，且未重复询问已知字段
- [ ] 页数区间由 `1.2 × 时长 ± 25%` 算出并写明上下限
- [ ] 视觉维度 ≥ 2 个有参数，且 5 项硬边界检查留"5/5 通过"
- [ ] 参考作品（如有）已 7 步拆解，可迁移规则 3–5 条
- [ ] 阻断冲突 0 条未决；可延后冲突均有 `[假设]` 与替代方案
- [ ] 确认书 6 区块齐全、≤ 1 页、无空字段、每条带标签与来源
- [ ] 用户已显式确认或已签授权卡（门禁 G1）
- [ ] 6 条完成标准（C1–C5 + G1）逐条勾选
