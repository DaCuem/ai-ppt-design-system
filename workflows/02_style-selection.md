# 02 设计方向研究与选择

把内容卡（01 产出）翻译成 3 个彼此不同的视觉方向，用可复算的评分选出 1 个主方向。本步不写页面，不做版式，只定「用什么视觉语言讲这件事」。

## 输入

| 输入项 | 来源 | 必需 |
|---|---|---|
| 项目简报 | `<project>/records/project-brief.md` | 是 |
| 风格条目 | `../references/visual-styles.md`，按条目逐条比对 | 是 |
| 版式清单 | `../references/layout-recipes.md` 的 L01–L15 | 是 |
| 素材条件 | 简报「可用素材」段：可用真实影像张数、是否有截图/数据表 | 是 |
| 用户指定风格 | 简报「用户指定风格 / 喜欢的参考 / 明确不喜欢的元素」 | 否 |

## 前置条件

- 01 已完成，简报 15 个字段无空值；有空值退回 `./01_intake-and-content-audit.md` 步骤 8。
- 叙事类型已定（1 主 + ≤ 1 辅）；未定则先回 01 步骤 6，本步不替它决定。
- 可用真实影像张数已数清（记为 N 张）；N = 0 时，方向里涉及实拍的方向直接按 R3 降权。

## 操作步骤

1. **起草 3 个方向**。每个方向按 8 栏写满：设计概念 / 视觉关键词 / 构图逻辑 / 色彩逻辑 / 字体层级 / 图像语言 / 适合页面 / 风险与不适用。判据：8 栏无空，且每栏是「可观察的描述」，不是形容词堆叠（例：写「标题左对齐 56–72 pt、正文单行 ≤ 34 字/行」，不写「文字层级清晰」）。
2. **差异化校验**。任取两个方向对比「构图逻辑 / 色彩逻辑 / 字体层级 / 图像语言」4 栏。判据：至少 3 栏取值不同，否则判定为同义方向，重做其中一个。
3. **写视觉参考依据**。每方向给 1–2 条知识库条目编号（来自 `../references/visual-styles.md`）作为依据，说明借用了它的哪条构图/色彩规则。判据：不写「业界常用」「某大师风格」这类不可核验表述。
4. **六项评分**。每方向每项 1–5 分：内容适配度 / 受众适配度 / 信息可读性 / 视觉辨识度 / 素材适配度 / 制作可行性。判据：18 个分数（3 方向 × 6 项）每个必须配 1 句理由，理由里含具体数值或素材事实（如「正文 18 pt 对 3–8 m 距离偏小，扣 1 分」）。
5. **汇总定主方向**。总分 = 6 项之和（满分 30）。主方向须满足：总分 ≥ 24、无单项 ≤ 2 分、比备选高 ≥ 2 分。判据：三项全中才可写入提案的「推荐方向」。
6. **留 1 个备选**。备选写「在什么条件下换用它」，例：用户不接受深色底时启用方向 B。
7. **混合风格分工**。允许混搭时，写清主风格承担构图与色彩、辅助风格只承担哪一类元素（如仅用于章节页）。判据：辅助风格覆盖页面 ≤ 20% 页数。
8. **写误用清单**。≥ 4 条「这个方向一做错会变成什么」，每条对应一个可观察现象与判据，供 06 阶段查。

### 三条执行规则

**规则 1｜用户指定风格优先**
**触发条件**：简报里用户已明确指定风格或给出参考作品。
**具体动作**：不换方向，把用户风格写成方向 A 并按 8 栏补全，再给「转化为演示文稿表达」的 3 条动作（如把网页长滚动改为 3 页递进）。评分低于 24 分时仍保留该方向为主方向，但必须在提案里写明代价与补偿动作。
**常见错误**：以「评分更低」为由擅自换风格，用户验收时认为需求未被执行。

**规则 2｜评分必须可复算**
**触发条件**：任意一项打分。
**具体动作**：先写理由句，再写分数；理由句含一个可测事实（字号 pt、对比度 :1、真实影像张数、可用于该类页面的素材占比 %）。
**常见错误**：六项都打 4 分，提案失去决策价值；用户无法判断为什么选 A 不选 B。

**规则 3｜无素材不得空转**
**触发条件**：某方向依赖实拍图或截图，而 N < 该方向所需张数。
**具体动作**：素材适配度 ≤ 2 分；若仍入选，必须在「风险」栏写替代方案（改用 L08 数据聚焦 / L10 分层体系 / L07 流程），并预估替换后视觉一致性代价。
**常见错误**：方向很依赖大图却无图，到 05 阶段才临时找图，导致整套图片风格失控。

## 判断与分支

| 条件 | 动作 |
|---|---|
| 两方向在 4 栏里只有 ≤ 2 栏不同 | 判为同义方向，重做差异最小的那个，直到 ≥ 3 栏不同 |
| 主方向最高总分 < 24 | 回 01 补充素材或缩减页数，再重评；不得直接把 4 分抬成 5 分 |
| 主备分差 < 2 | 增加第 4 个方向，或把两个方向做成单页样张交用户二选一 |
| 用户指定方向总分 < 24 | 保留为用户主方向，提案里写明 3 条代价与补偿动作 |
| 素材适配度 ≤ 2 的方向排第一 | 降为备选；主方向换成素材适配 ≥ 3 的 |
| 用户喜欢的参考与已定叙事类型冲突 | 借参考的视觉规则（色彩/构图），不改叙事结构；冲突写进提案「需确认事项」 |
| 两方向需要完全不同配色 | 允许，但只能有一个进入 03；另一个留作废稿存档 |

## 输出文件

- `<project>/records/design-proposal.md`：按 `../templates/design-proposal.md` 填写，含 3 个方向 × 8 栏、18 个分数与理由、对比与推荐、误用清单。
- 同文件附录：评分汇总表（方向 × 6 项 + 总分）、需用户确认事项（≤ 3 条）。
- 主方向确定后，`../references/layout-recipes.md` 中被点名的版式编号抄进 04 的起始清单。

## 完成标准

- 方向数 ≥ 3，每方向 8 栏无空值。
- 任意两方向在 4 个核心栏中 ≥ 3 栏取值不同。
- 18 个分数全部有理由句，理由句含至少 1 个带单位数值或素材事实。
- 主方向：总分 ≥ 24、无单项 ≤ 2、领先备选 ≥ 2 分。
- 误用清单 ≥ 4 条，每条能在渲染图上被观察到。
- 混合风格时，辅助风格覆盖页数 ≤ 20%。

## 失败处理

| 类别 | 具体处理 |
|---|---|
| 缺素材 | 按规则 3 降权并给替代版式；N = 0 时 3 个方向全部只用 L08/L10/L07/L13，图像语言栏改写为「结构图 + 数据表」 |
| 缺数据 | 不评「内容适配度」中的数据支撑项；在提案里标「该方向依赖尚未获得的数据」，04 阶段改用定性页 |
| 工具不可用 | 无法生成样张（渲染后端不可用）时，用 ASCII 线框 + 色值表代替样张，并在提案注明「样张待渲染，版式结论为推定」 |
| 内容冲突 | 用户指定风格与素材/受众冲突 → 方向 A 保留用户风格 + 3 条补偿动作，冲突记入「需确认事项」，不擅自裁决 |

## 检查清单

- [ ] 方向数 ≥ 3，每个方向 8 栏全填
- [ ] 任意两方向有 ≥ 3 栏实质不同（构图 / 色彩 / 字体 / 图像）
- [ ] 每个方向引用了 ≥ 1 个真实知识库条目编号
- [ ] 18 个分数全部带理由，理由含带单位数值或素材事实
- [ ] 主方向总分 ≥ 24、无单项 ≤ 2、领先备选 ≥ 2 分
- [ ] 备选方向写了启用条件（1 句，可判定）
- [ ] 混合风格时辅助风格覆盖页数 ≤ 20%
- [ ] 误用清单 ≥ 4 条，每条有可观察现象
- [ ] 「需确认事项」≤ 3 条，每条有默认处理方式
- [ ] 提案未出现未核验的外部风格来源表述
