# 04 整套页面架构与叙事节奏

把内容卡排成一条有时间感的叙事，而不是把原文逐段搬上页面。本步输出「每页一句话结论 + 版式编号 + 焦点位置」的规划表，不写元素坐标。

## 输入

| 输入项 | 来源 | 必需 |
|---|---|---|
| 项目简报 | `<project>/records/project-brief.md` | 是 |
| 主方向 + 视觉系统 | `<project>/records/design-proposal.md` | 是 |
| 版式清单（L01–L15） | `../references/layout-recipes.md`，编号以仓库根 `_layout-index.md` 为准 | 是 |
| 节奏规则 | `../references/presentation-rhythm.md` | 是 |
| 页数与时长 | 简报「演讲时长与页数范围」 | 是 |

## 前置条件

- 03 已完成：`tokens` 落盘且通过 `../schema/deck.schema.json` 校验；未完成退回 `./03_visual-system.md`。
- 叙事类型已定（1 主 + ≤ 1 辅）；未定退回 `./01_intake-and-content-audit.md` 步骤 6。
- 页数已按 时长 ÷ (0.75–1.25 min/页) 估算，并与用户确认页数区间；无区间不得开工。

## 操作步骤

1. **定页数区间**。页数 = 时长(min) ÷ 1.0 min/页，允许 ±25% 浮动。判据：结果落在简报区间内，且覆盖页 + 收尾页 ≤ 总页数 × 20%。
2. **一页一句核心结论**。每页写 1 句「观众看完应记住的话」，≤ 25 字（`thresholds` 的标题字数上限 25 字）。判据：任意两页结论不得是同一句话的改写；结论必须是判断句，不能是「介绍 X」这类标签。
3. **判定信息结构**。逐页从 9 类中选 1 类：时间序、两组差异、多因素关系、单一核心证据、产品结构、操作过程、观点论证、多类别并列、成果展示。判据：每页只选 1 类；混合时取主导类，次要类写进页面备注。
4. **按结构选版式**。结构 → 版式映射：时间序 → L06 时间线·阶段 或 L07 流程·步骤；两组差异 → L05 对照比较；多因素 → L09 矩阵·定位 或 L10 分层·体系；单一证据 → L08 数据聚焦 或 L12 图片主导；产品结构 → L11 产品结构·分解；操作过程 → L07；观点论证 → L04 结论+证据 或 L03 单点陈述；多类别并列 → L13 编辑式多栏；成果展示 → L12 + L08 组合。判据：每页有且只有 1 个 L 编号；不得为「好看」换编号。写法：首次出现写「版式 L08（数据聚焦）」，之后只写编号，不写自创编号；一页混合两类关系时取主导编号，另一类写进 `notes`，并用 `gridTemplate` 区分。
5. **定视觉焦点**。用九宫格位置：`tl/tc/tr/ml/mc/mr/bl/bc/br/full/none`。判据：每页 1 个焦点（`none` 仅用于纯章节页或引文页）；焦点面积占页面 ≥ 20%（`full` 除外）。
6. **写前后页关系**。每页写清「承接上一页的哪一句 / 为下一页留下什么问题」，二选一必填。判据：不得出现「独立」；相邻页若无逻辑连接则合并或删除。
7. **标风险**。风险类型至少覆盖：文字超 220 字、证据不足、图像缺失、版式与相邻页重复、数据口径未定。判据：风险列非空的页数 ≤ 总页数 × 20%。
8. **节奏检查**（见下表判据）。任一不通过则调整顺序或换版式，直到全部通过。

### 节奏检查（三项，全部要过）

**规则 1｜能量曲线**
**触发条件**：每页标能量 1–5（1 = 章节页/引文页，3 = 常规正文，5 = 封面/关键证据页）。
**具体动作**：全场至少 2 个 5 级峰值（开场 + 结论前一次关键证据），相邻页能量差 ≤ 2，不得连续 4 页能量 ≤ 2。
**常见错误**：每页都标 3 级，曲线成直线；观众在第 5 页后失去注意力节点。

**规则 2｜版式重复**
**触发条件**：相邻页 `layout`、`gridTemplate`、`focalPosition` 三项完全相同（`thresholds.repetition.signatureFields`）。
**具体动作**：相邻同签名页数 ≤ 1；任一签名占比 ≤ 35%；焦点位置连续相同 ≤ 2 页。违反则换版式或换焦点位置。
**常见错误**：连续 4 页「左图右文」，06 阶段按 REP-01 判 P1。

**规则 3｜疏密交替**
**触发条件**：密页 = 元素 ≥ 8 个或字数 ≥ 160 字；疏页 = 元素 ≤ 4 个或字数 ≤ 80 字。
**具体动作**：连续密页 ≤ 2；每 4 页内至少有 1 次密→疏或疏→密的变化；封面后第 1 页不得为密页。
**常见错误**：整套都是 6 个信息块的密页，读起来像文档投影。

## 判断与分支

| 条件 | 动作 |
|---|---|
| 页数超出区间上限 | 合并同一论点的页，或把 2 个 L13 并列页并成 1 页；不删结论页 |
| 某页结论无法压到 25 字 | 拆成 2 页：1 页结论 + 1 页证据；或删掉该论点（回 01） |
| 信息结构判不出唯一主导类 | 取「观众要回答的问题」定类：是什么→L10，怎么变→L06，选哪个→L05，凭什么→L04 |
| 相邻页版式重复且无法改 | 保留但改焦点位置 + 改 `gridTemplate`，并在备注写必要性；占比仍须 ≤ 35% |
| 证据页数据未到位 | 该页改用 L03 单点陈述，标「待补数据」；不得先画空图表 |
| 页数 < 8 页 | 不设章节页，L02 用量为 0，直接 L01 → L04 → L15 |
| 用户要求固定页数 | 以页数为硬约束重排，优先删重复论点与合并步骤页，保留结论页 |

## 输出文件

- `<project>/records/deck-outline.md`：按 `../templates/deck-outline.md` 填写 9 栏表（页码 / 页面任务 / 核心结论 / 证据/素材 / 信息结构 / 推荐版式 / 视觉焦点 / 与前后页关系 / 风险）。
- 同文件附录 A：节奏表（页码 / 能量 / 密疏 / `layout` / `gridTemplate` / `focalPosition`）。
- 同文件附录 B：章节划分表（章节名 / 起止页码 / 章节页页码）。
- 下游：05 逐页取本表一行，写成 `slide-spec`。

## 完成标准

- 页数落在 时长 ÷ (0.75–1.25 min/页) 区间，且与用户确认值一致。
- 每页核心结论 1 句、≤ 25 字、为判断句；全表无重复结论。
- 每页信息结构 ∈ 9 类之一，`layout` ∈ L01–L15 之一，`focalPosition` ∈ 11 个枚举值之一。
- 能量 5 级峰值 ≥ 2 个；相邻页能量差 ≤ 2。
- 相邻同签名页 ≤ 1；最大签名占比 ≤ 35%；连续密页 ≤ 2。
- 风险列非空页数 ≤ 总页数 × 20%。
- 覆盖页 + 收尾页 ≤ 总页数 × 20%。

## 失败处理

| 类别 | 具体处理 |
|---|---|
| 缺素材 | 该页改用 L08（数据聚焦）或 L10（分层体系）承载，风险列写替代方案；不留空页 |
| 缺数据 | 结论页改 L03，证据页标「待补数据 + 数据来源类型」；节奏照常检查 |
| 工具不可用 | 无法渲染样张时，用 9 栏表 + 附录节奏表代替视觉稿；注明「版式效果待 05 渲染验证」 |
| 内容冲突 | 用户给的页序与叙事逻辑冲突 → 按用户页序执行，把「逻辑断裂风险 + 建议合并页」写进需确认事项 |
