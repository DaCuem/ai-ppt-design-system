## 判定口径

| 级别 | 判定标准（详见 schema/thresholds.json 与 workflows/06_quality-assurance.md） |
|---|---|
| P0 | 元素出画布、文字溢出 > 框高 30%、w/h ≤ 0：阻断交付 |
| P1 | 溢出 > 0.02 in、字号低于下限、对比度不足、相邻页版式重复、缺 alt、图表缺 unit/source、slide id 不连续、阈值键缺失 |
| P2 | 每行字数超限、标题正文比失衡、密度超限、单签名占比 > 35%、非法颜色、字族 > 3、标题 > 25 字 |
| P3 | 段行数超限、文本块重叠、留白不足、字号不在阶梯、缺页码 |

注：P1–P3 不阻断交付，但同一条检查 ID 在多页重复出现时按系统性问题处理——改 `tokens` 或版式，不逐页补。
