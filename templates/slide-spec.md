# 单页规格 slide-spec

用途：05 单页制作的产出，一份文件对应一页，或在一份文件里按页分节。保存到 `<project>/records/slide-spec.md`。

## 规格表

| 字段 | 填写内容 | 填写提示 |
|---|---|---|
| 页面标题 | | 结论式，≤ 25 字 |
| 核心信息 | | 一句话，能说出口 |
| 观众应记住 | | 只写 1 件事 |
| 信息分组 | | 2–4 组，每组有名 |
| 阅读顺序 | | 写 1→2→3，不写箭头图 |
| 视觉焦点 | | 九宫格枚举之一 |
| 构图描述 | | 区块位置与面积占比 |
| 文字层级 | | role 与 pt 逐条列出 |
| 色彩使用 | | tokens 键名 + 面积占比 |
| 图片图表 | | 文件名、类型、单位 |
| 与全局系统的关联 | | L 编号 + gridTemplate |
| 不要出现 | | 明确排除的元素 |

## 填写示例（已填 s07）

- 页面标题：产线停机 12 分钟，90% 发生在换型后 3 分钟内（24 字）。
- 视觉焦点：mr；构图：左侧 3 组数据块占 55% 宽，右侧折线图占 40% 宽。
- 文字层级：h2 28 pt / body 18 pt / caption 12 pt；色彩：fg 65%、accent 8%、bgAlt 27%。
- 图片图表：chartType=line，unit=分钟，source=产线 2025 年 11 月统计。

## 自检

1. 12 个字段全部有值，标题、字号、坐标都能直接写进 `source/deck.json`。
2. 每页文字总量 ≤ 220 字、bullet ≤ 6 条，超了先删不先缩字号。
3. 「不要出现」列至少 1 条，且是可判定的元素名。

## 检查清单

- [ ] 标题是结论句，≤ 25 字
- [ ] 视觉焦点是九宫格枚举值之一
- [ ] 字号全部落在 `../schema/thresholds.json` 的 role 区间内
- [ ] 色彩只引用 `tokens.colors` 的键名，未新造色值
- [ ] 图表写清 unit 与 source，图片写清文件名与 alt
- [ ] 与 `deck-outline.md` 同页的 L 编号一致
