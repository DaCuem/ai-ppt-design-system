# 换模型改写 · 交接提示词模板

> 用途：走 `references/copywriting-antislop.md` §3 的 **P3 换模型**路径时，把这份模板填好，整段发给另一个模型。
> **设计原则：只传用户要求，不传本 skill 的写作规则。** 句式偏好、禁用词表、检查项全部留在本地——它们的作用是回来之后做验收，不是提前给对方套笼子。
> 复用到 `records/copy-crosscheck.md`：每批一次，批与批之间不共享上下文。

---

## 一、发给对方的完整内容（从下面一行开始复制）

```
你是文案改写者。任务：把下面这份演示文稿的逐页文案改得更像人写的，然后直接交回改后的完整文案。
不要写建议、不要写理由、不要说明你改了什么。只交成品。

【一、这份稿子的使用条件】
- 受众：{受众，例如"校内评审老师 3 人"}
- 场合与时长：{场合，例如"15 分钟答辩"}
- 语气：{对评审 / 对客户 / 对同事 / 对公众}
- 人称：{第三人称 / 第一人称复数}
- 用词偏好与禁忌：{用户指定的禁用词、厂内代号、竞品名；没有就写"无"}
- 必须逐字保留：{数字、单位、专有名词、引用出处；没有就写"全部数字与单位"}

【二、版面的物理限制（不是文风要求）】
每个格子能放的字数有限，超了会挤出版面，届时只能删内容：
| 槽位 | 上限字数 |
|---|---|
| coverTitle | {20} |
| lead | {64} |
| h1 | {25} |
| h2 | {30} |
| h3 | {34} |
| body | {220} |
| bullet | {34} |
| kpi | {40} |
| label | {24} |
| caption | {72} |
| source | {72} |
除这一条，没有别的写法要求——怎么断句、怎么起头、用什么语气，你自己判断。

【三、输出格式（只输出这个）】
按页、按槽位给完整文案；**没有改动的槽位也要逐字抄回来**，一行不许省。

| 页 | 槽位 | 改后文案 |
|---|---|---|
| 01 | coverTitle | …… |
| 01 | lead | …… |
| 02 | h1 | …… |

最后一行只写：`END {总页数} 页 / {总槽位数} 个槽位`

【四、禁止】
- 不要输出"建议""理由""我把……改成了……"这类文字
- 不要输出 diff 或标注改动位置
- 不要省略未改动的行
- 不要改数字、单位、专有名词、引用出处
- 不要加页、不要合并页、不要调整顺序

【五、待改文案】
{逐页贴入，格式：页号 | 槽位 | 原文}
```

## 二、故意不传的东西（这一节决定了它还是它，不是我）

| 不传 | 为什么不传 |
|---|---|
| 本 skill 的句式规则（一页一句主张、结论前置、信息不重复） | 这是我总结出来的偏好。传过去，它只会产出"像我"的句子——那还是同一个模子的文案，只是换了个模型执行 |
| 空话清单、AI 句式正则、填充形容词表 | 一旦给了「不要写赋能、不要写不仅…而且」，它就绕开这些词，而没有真正改变句子的组织方式——这是绕过检测，不是改文风 |
| 机检结果（CP-01…CP-10） | 把这些当指令发过去，等于让它在约束下填空；收回来的东西是"通过检查的文案"，不是"人写的文案" |
| 抽样范例（我写的"好句子"） | 范例会被模仿，产出变成我文风的复制品 |
| 我判断"哪几句像 AI"的结论 | 判断权在用户（`copywriting-antislop.md` §1）。我标了它就只改那几句，其余问题原样留着 |

只传的一件例外是**版面字数上限**——这是物理约束，不是文风偏好：超过就放不进固定版面，而删哪句不该由我替用户决定。

## 三、收回后怎么处理（我的动作，不是对方动作）

1. **先查完整性**：行数、页数、槽位数对不对；加页/合并页/漏槽位 → 整批退回重跑，不许自己补。
2. **按「页 + 槽位」覆盖**进 `records/copy-deck.md`，保留它给的原文，一个字都不润色。
3. **算 diff 给用户看**：`页 | 槽位 | 原文 → 新文`。这是用户判断"接不接受"的唯一依据。
4. **跑机检但不当令箭**：`python scripts/copy_check.py --deck source/deck.json --copy records/copy-deck.md` 的结果只作为**事实清单**交给用户（哪页哪句超了多少字、命中哪条），**不拿它回炉要求对方改**。
5. **超字数的处理**：不擅自删句。把超出的项列出来问用户——压字数 / 改版式 / 换一版？三选一。
6. 走 `copywriting-antislop.md` §5 的三问，等用户签字；不替用户下结论。

## 检查清单

- [ ] 提示词里只出现「使用条件 + 篇幅上限 + 输出格式 + 四条禁止」，没有我的句式规则与禁用词表
- [ ] 对方回的是完整文案表格，不是建议或理由
- [ ] 槽位数与合并前一致，无加页、无合并页
- [ ] `records/copy-deck.md` 里 `[待确认]` 为 0
- [ ] 机检结果只作为事实清单给用户，没有当成"退回重改"的命令
- [ ] 超字数的项列给用户三选一，没有擅自删句
- [ ] 交给用户的 diff 是「页 + 槽位 + 原文 → 新文」
- [ ] 用户答复与签名落点记录在案（`[已确认]` 或 `[假设]`）
