# 素材与字体许可记录规范

任何外部素材进入产出物之前，都必须先在本文件对应的表格里留下一条记录。**没有记录的素材不得使用。**

核验日期统一写 `YYYY-MM`；许可条款以官方许可文本为准，本文件的速查表只用于判断方向，不替代原文。

---

## 1. 必须记录的字段

| 字段 | 说明 | 示例 |
|---|---|---|
| 素材 ID | `类型-主题-序号`，与文件名一致 | `img-hero-windtunnel-01` |
| 出现在哪页 | 页码与元素 | `P03 主视觉` |
| 来源 | 原始页面标题或作者 + 获取方式 | `作者自摄` / `机构官网图库` |
| 许可类型 | 见第 2 节速查表 | `CC BY 4.0` |
| 可否商用 | 是 / 否 / 需授权 | `是` |
| 署名要求 | 具体署名文字 | `Photo: 张×× / CC BY 4.0` |
| 修改说明 | 是否裁切、调色、叠加 | `裁切为 16:9，统一降饱和 15%` |
| 核验日期 | `YYYY-MM` | `2026-11` |

---

## 2. 许可速查表

### 2.1 图片与图形

| 许可 | 可商用 | 需署名 | 可否修改 | 主要限制 |
|---|---|---|---|---|
| CC0 1.0 | 是 | 否 | 是 | 无（不建议暗示原作者背书） |
| Public Domain | 是 | 否 | 是 | 无 |
| CC BY 4.0 | 是 | 是 | 是 | 必须署名并标注是否修改 |
| CC BY-SA 4.0 | 是 | 是 | 是 | 衍生作品须同许可共享 |
| CC BY-NC 4.0 | **否**（商业用途） | 是 | 是 | 商业提案、产品发布中不可用 |
| CC BY-ND 4.0 | 是 | 是 | **否** | 不得裁切、调色、叠加文字 |
| Unsplash License | 是 | 否（建议） | 是 | 不得出售未修改副本，不得用其内容搭建同类图库服务 |
| Pexels License | 是 | 否（建议） | 是 | 不得转售原图，不得暗示人物背书 |
| 商用图库（授权制） | 按合同 | 按合同 | 按合同 | 需保存授权凭证与订单号 |

### 2.2 字体

| 字体 | 许可 | 可否随文件分发 | 说明 |
|---|---|---|---|
| Noto Sans SC / Noto Serif SC | SIL OFL 1.1 | 可以（保留版权声明） | 开源，适合作为跨平台首选与回退字体 |
| 思源黑体 / 思源宋体（Source Han） | SIL OFL 1.1 | 可以（保留版权声明） | 与 Noto CJK 同源 |
| Lato | SIL OFL 1.1 | 可以 | 西文无衬线，字重齐全 |
| 微软雅黑 / 黑体 / 宋体（Windows 自带） | 商业授权，随系统 | **不可** | 只能在已授权的系统上使用，不得打包进交付物 |
| 苹方 / 华文系列（macOS 自带） | 商业授权，随系统 | **不可** | 同上 |
| Arial / Georgia / Times New Roman | Monotype 商业授权 | **不可** | 随系统或 Office 提供，不可分发 |

**实践规则**：

1. 交付 PPTX 时**默认不嵌入字体**。若确需嵌入，先确认该字体的许可允许嵌入（系统商业字体通常不允许）。
2. `tokens.fonts.fallback` 必须写出回退链，且回退后版面不得溢出（用 `scripts/qa_check.py` 换字体复核一次）。
3. 核心信息不得依赖某一款特殊字体的字形表达（如用极细字重表达"轻盈"）。

## 4. 核验流程（4 步）

1. **定位许可**：在素材原始页面上找到许可声明；找不到 → 视为"未授权"，不用。
2. **判类型**：按第 2 节速查表判断商用与署名要求；不确定 → 不用。
3. **落记录**：填第 3 节表格，包含署名文字原文。
4. **落页面**：署名需要出现在页面上时（如 CC BY），必须在图注或页脚真实写出，不能只写在记录表里。

---

## 5. 禁止事项

- 用搜索引擎结果页当来源（无法追溯版权）。
- 把"网上找的"写进记录表当来源。
- 用 AI 生成图冒充真实产品照片、真实用户评价、真实实验现象。
- 使用 CC BY-NC 素材做商业提案或产品发布。
- 使用 CC BY-ND 素材后裁切、调色、叠加文字。
- 声称"已获授权"但没有授权文本。

## 检查清单

- [ ] 每个外部素材都有记录，字段齐全（8 项）
- [ ] 商用场景下没有 CC BY-NC 素材
- [ ] 需要署名的素材，署名真实出现在页面上
- [ ] 交付物未嵌入系统商业字体
- [ ] `tokens.fonts.fallback` 已写，且换字体后经 `qa_check.py` 复核无溢出
- [ ] 没有 AI 生成图被当作真实照片/真实成果
- [ ] 所有核验日期为 `YYYY-MM` 格式，且不晚于交付日期
