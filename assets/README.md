# 素材目录说明

## 这里放什么

`assets/` **只放规范与记录**，不放素材本体。原因有三：

1. 素材许可各不相同，把图片/字体打进仓库等于替使用者承担授权风险；
2. 仓库体积会失控，skill 的下载与更新会变慢；
3. 真实项目素材是用户自己的资产，不属于本仓库。

实际素材放**每个项目自己的目录**：

```
<project>/source/assets/
├── img/            # 位图与矢量图
├── charts-data/    # 图表原始数据（csv/xlsx/json）
└── asset-licenses.md   # 本项目的素材许可记录（复制 assets/licenses.md 的表格）
```

## 命名规范

```
img/<用途>-<主题>-<序号>.<ext>
例：img/hero-windtunnel-01.jpg、img/diagram-control-loop-01.svg
```

- 用途：`hero`（主视觉）/ `evidence`（证据）/ `bg`（背景）/ `decor`（装饰）/ `icon` / `chart`
- 只用小写、连字符、ASCII；不用中文、空格、括号。
- 同一张图的不同裁切版本加后缀 `-43`（4:3）、`-169`（16:9）。

## 分类与处理要求

| 类型 | 要求 |
|---|---|
| 照片 | 记录来源与许可；裁切留主体安全区 8%；同组统一色调 |
| 图表数据 | 必须能追溯到原始文件；注明口径、单位、时间范围、n= |
| 图标 | 只用一套；单调色；线宽统一；数量 ≤ 每页 1 组（见 `references/anti-patterns.md` AP-04） |
| 纹理/背景 | 允许程序化生成（渐变、噪声），但不得伪装成真实照片 |
| AI 生成图 | 必须标注"示意图"，不得作为项目真实成果、真实用户、真实产品照片使用 |

## 缺素材时的优先级

真实素材 > 结构图/示意图 > 留白 > AI 生成图。

任何降级都要写进 `records/qa-report.md` 的遗留问题，不能静默替换。
